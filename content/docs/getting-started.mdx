## Open the Studio

Use the hosted Studio at [glyphfield.com/studio](https://www.glyphfield.com/studio), or run it locally:

```bash
pnpm install
pnpm dev
```

The local Studio runs at `http://localhost:3012/studio`. Glyphfield uses pnpm 11; see [Self-hosting](/docs/reference/self-hosting) for production builds.

## 1. Choose a project

A project holds one brand identity and the work of every tool. Projects open as tabs above the tool. The **Projects** menu sorts them into four folders:

- **Templates**: the Starter identity, original Glyphfield work to start from.
- **Examples**: reference identities for Basement, General Translation, Ramp, Mintlify, Tailwind CSS, Vite+, Cloudflare, and Stripe.
- **My brands**: projects you create, copy, or import.
- **All projects**: everything.

Closing a tab only closes its view; the project stays in **Projects**. Built-in projects can be edited in place and restored to their shipped version.

The **+** beside the tabs (**Add brand project**) opens **New project**:

- **Start from scratch** with an empty **Design Lab** design, **Animation**, or **Brand identity**.
- **Use a template** to copy one of the nine built-in identities into a new project named `<Name> copy 1`.
- **Import project…** to open a `.glyphfield.json` file as a new project. Glyphfield validates the file in the browser and opens it in Design Lab or Animation. An invalid file shows an error and creates nothing.

**Project → Duplicate active project** copies the identity, the current work in every tool, assets, and saved checkpoints, including edits still waiting to autosave. The copy opens in a new tab and is independent. If the copy fails, **Could not duplicate project: show details** explains why.

Agents use the same controls by accessible label: activate **Add brand project**, then the menu item. For a file chooser, provide a `File` built from authorized bytes. In Brand identity, `identity.project.create` creates a project directly. After a project opens, wait for `glyphfield:studio-api-ready`, then call `readSource()` before editing.

## 2. Set the identity

Open **Brand identity**. The overview shows the brand cover, the brand health score, and what is defined. The editors cover:

- **Voice & strategy**: challenge, concept, promise, outcome, pillars, personality, voice principles and examples, audiences, products with one-line summaries, proof, customers, and sample content for templates.
- **Logos & assets**: five logo slots, the asset library with licenses and sources, and the conversion library.
- **Color system**: palette colors with shares and the declared text pairs.
- **Typography**: font files and the Display, Body, Accent, and Code roles, and the type scale.
- **System defaults**: density, radius, logo scale, the graphic device, pattern, and rules.
- **Direction & references**: the art-direction dossier, applications, and references.

**Set up with agent** gives Claude Code, Codex, or Cursor a prompt that fills these sections from the brand's own website, repository, or design files. **Brand health** lists what is missing or failing, with one-click fixes. **Brand kit** downloads tokens and guidelines for code. Every tool reads the saved identity, so a change here flows into boards, the brand book, templates, components, motion, and Design Lab defaults. See [Brand identity](/docs/studio/brand-settings).

## 3. Find a tool

Use the left navigation, or press ⌘K / Ctrl+K and search for a capability such as `email`, `logo`, `dither`, `slide`, or `terminal`. Tools are grouped into Brand, Motion, Foundations, Expressions, and Components. The [Studio overview](/docs/studio) lists all fifteen.

## 4. Compose and inspect

Most tools share one layout:

- The left sidebar holds libraries, catalogs, and sources.
- The center canvas renders the artifact. Scroll to zoom, drag empty space to pan, and use the toolbar to fit or reset the view.
- The right inspector edits the selected layer or the tool's settings.
- **File → Edit source code** opens the artifact's exact JSON in a drawer. **Apply code** validates and applies it; an invalid edit leaves the artifact unchanged.
- The tool header holds saving and export.

**Visual customization** sets the Studio theme (Light, Dark, Auto), accent, canvas background, corners, density, reduced motion, and the interface font: Helvetica Neue (the default), Be Vietnam Pro, Schibsted Grotesk, or Rethink Sans. These settings never change brand colors in an artifact.

For a first composition, open **Design Lab**:

1. Choose **Artboard setup** for the output size, for example Wide 1600 × 900 or OG Social 1200 × 630.
2. Add text (T), a brand mark (M), an image (I), or pick a shader from the Shader Library.
3. Select a layer to edit its geometry, appearance, opacity, and material.
4. Scrub shader time to choose an exact frame, and **Capture shader frame** to keep it.
5. **Save checkpoint** before producing variants.

## 5. Export

Export actions are specific to each tool. Common outputs:

- PNG for lossless stills from every visual tool
- JPG for smaller opaque Design Lab stills
- GIF for Design Lab, Animation, and Lottie motion
- MP4 for browser-encoded video, including Animation audio
- PDF for the Brand book and slide decks
- SVG for expression tools, moodboards, and HTTP templates and backgrounds
- HTML for brand element emails
- JSON for identities, briefs, project files, and Lottie

Check dimensions, clipping, background, text contrast, motion, and file type in the export review before downloading. A click is not the artifact: confirm the downloaded file is non-empty and opens in its target application.
