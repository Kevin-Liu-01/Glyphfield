`POST /api/generate` accepts `application/json`. The request `kind` selects one of four generators: `template` (the default), `background`, `element-brief`, and `design-sequence`. `GET /api/generate` returns the current contract (`schemaVersion` 3) with the request schema, enums, limits, and examples. Read it before building a request.

## Output selection

- `output: "json"` is the default for SVG generators. The response contains metadata and `artifact.content`.
- `output: "raw"` returns `image/svg+xml` directly.
- `element-brief` always returns JSON.
- `design-sequence` returns an apply-ready Design Lab document, its resolved shader timeline, and browser API commands.

## Design sequence

Design sequence creates the same versioned composition used by Design Lab. It supports an identity-aware brand mark, up to 32 text layers, a Bayer, ASCII, halftone, or posterize converter, any material listed by `/api/materials`, 8–12 cuts, and a 3–6 second final hold. Unlisted (retired) material IDs are rejected. Image effects are added in the browser with `design.effects.add` after the document is applied.

```json
{
  "kind": "design-sequence",
  "identity": { "preset": "gt" },
  "ratio": "wide",
  "backgroundColor": "#111216",
  "shader": {
    "materialId": "paper-gem-smoke",
    "shaderSize": 1
  },
  "sequence": {
    "cutCount": 10,
    "finalHoldMs": 5000,
    "pace": "accelerating"
  },
  "effect": {
    "kind": "bayer",
    "opacity": 0.76,
    "foreground": "#F5F5F2",
    "background": "#111216"
  },
  "texts": [{ "value": "Open Source", "weight": 500 }],
  "export": { "width": 1920, "fps": 30, "quality": "best" }
}
```

The response is JSON with:

- `schemaVersion: 1`: the HTTP response-envelope version.
- `document`: an apply-ready Design Lab compatibility source with `version: 3`.
- `sequence.timeline`: resolved material IDs and cut boundaries.
- `automation`: the stable browser global and exact apply/export commands.

`document.version` is not the active canvas schema. `applySource(response.document)` validates and migrates the compact compatibility source, then the Design Lab adapter exposes the normalized result as CanvasDocument schema 2 with Design Lab source metadata version 4. Re-read source after application before making targeted CanvasDocument edits.

Apply and render inside `/studio`:

```js
await window.glyphfield.studio.applySource(response.document);
const artifact = await window.glyphfield.studio.invoke(
  'design.export',
  { format: 'mp4', mode: 'shader-sequence', download: true }
);
```

Choose `png`, `jpg`, `gif`, or `mp4`. Shader-sequence mode is available for GIF and MP4. The export action resolves to the real UI artifact object and uses the authentic shader canvases, composition effects, text, marks, layer order, and output settings; `download: true` also saves it.

## Templates

Template renders the Studio's brand templates as standalone SVG: OpenGraph images, terminal cards, slides, blog covers, and partnership lockups. Output uses the same layouts and renderer as the Studio and embeds the brand's font files and images, so it renders in the brand face in a plain `<img>`. A font whose data URL exceeds 560,000 characters is not embedded. Each request renders one page. Without copy, the identity supplies it: its headline and voice, its proof figures for metrics, its strategy pillars for agendas, and its own proof partner (or a written **Partner** placeholder) for lockups.

```json
{
  "kind": "template",
  "template": "slides",
  "slideLayout": "agenda",
  "texture": "white",
  "title": "One system, every market.",
  "body": "Foundation\nExpression\nApplication\nDelivery",
  "identity": { "preset": "gt" },
  "output": "raw"
}
```

### Template enums

- `template`: `slides | blog | partnership | opengraph | terminal`
- `texture`: `white | dark | grid | noise`
- `slideLayout`: `title | section | agenda | split | metrics | quote | timeline | statement | comparison | process | chart | team | image | closing`
- `layout` (other templates): opengraph `split | statement | media | centered | editorial`; blog `editorial | feature | statement | centered | ledger`; terminal `card | split | focus | caption`; partnership `lockup | centered | hero | announcement`
- `format`: `opengraph | wide | square | portrait | story | linkedin | lockup`; slides `16x9 | 4x3 | square`
- `language` (terminal): `typescript | tsx | javascript | python | bash | json | html | css`

| Field | Values |
| --- | --- |
| `template` | Default `slides` |
| `layout`, `slideLayout` | One of the template's layouts. `slideLayout` applies to slides; `layout` is also accepted for slides. Sending both is an error |
| `title` | Up to 240 characters |
| `body` | Up to 1000 characters, or 4000 for `terminal`. The list for slides (one item per line), the code for terminal, and the supporting copy on layouts that have a supporting-copy slot; other layouts ignore it |
| `background`, `foreground` | Six-digit HEX overrides |
| `backgroundImageDataUrl` | A base64 image data URL, up to 5 MB |
| `partnerId` | A partner for `partnership`: a proof asset ID of the identity, another built-in identity, or `template-northstar` |
| `partnerLogoDataUrl` | A base64 partner logo, up to 5 MB |
| `output` | `json` (default) or `raw` |

Default sizes are 1600 × 900 for slides, 1200 × 630 for OpenGraph, terminal, and blog, and 1200 × 600 for partnership; `format` changes them. The file name is `<identity slug>-<template>-<width>x<height>.svg`.

`identity` accepts `{ preset }` with optional overrides, `{ id }` with an ID from `/api/identities`, or the complete identity object from `/api/identities` (custom identities included). The default preset is `starter`. An unknown `id` returns `unknown_identity` and an invalid full identity returns `invalid_identity`. Any other field next to `preset` is rejected with `unknown_field` rather than silently rendering Starter. See [Identities and custom assets](/docs/agents/identity-assets).

## Background

Background generates gradient, grain-gradient, dither, pattern, and tactile surface SVGs. [Tactile backgrounds](/docs/studio/logo-background) lists every setting, including the `surface*` fields and the CC0 surface references.

```json
{
  "kind": "background",
  "identity": { "preset": "gt" },
  "settings": {
    "width": 1200,
    "height": 630,
    "style": "grain-gradient",
    "gradient": "mesh",
    "angle": 32,
    "colorA": "#FFFFFF",
    "colorB": "#181818",
    "colorC": "#737373",
    "focalX": 42,
    "focalY": 38,
    "relief": 24,
    "grain": 18,
    "pattern": "dots",
    "patternOpacity": 14,
    "spacing": 24,
    "logoTone": "black",
    "logoScale": 24,
    "logoOpacity": 100,
    "logoX": 0,
    "logoY": 0
  },
  "output": "raw"
}
```

Width and height must each be 64–4096 (`invalid_dimensions`), and the total may not exceed 12,000,000 pixels (`pixel_limit`).

## Element brief

Element brief resolves a stable record from `/api/elements` against an identity.

```json
{
  "kind": "element-brief",
  "elementId": "email-signature",
  "identity": {
    "preset": "custom",
    "name": "Acme",
    "website": "acme.test",
    "tagline": "Tools for careful teams."
  }
}
```

The response is `{ element, generation: { previewFamily, source: '/api/elements' }, identity, schemaVersion: 1 }`. `element` is the catalog record (ID, name, category, dimensions, format, symbol, keywords). `identity` holds the resolved colors, description, ID, name, positioning, short name, tagline, typography, voice, and website. The HTTP brief has no editor settings and does not rasterize an image; the Studio's **Download element brief** adds the element's current settings.

## JSON artifact envelope

```json
{
  "schemaVersion": 1,
  "artifact": {
    "content": "<svg ...>...</svg>",
    "filename": "general-translation-slides-1600x900.svg",
    "mimeType": "image/svg+xml",
    "width": 1600,
    "height": 900
  }
}
```

Check `schemaVersion`, `mimeType`, and dimensions before storing the content.

## Studio source is a separate contract

The **Code** drawer inside `/studio` serializes the active browser tool. It supports exact edits for identities, boards, Animation, Lottie, Design Lab, templates, foundations, and components. Design Lab uses CanvasDocument schema 2 with Design Lab metadata source version 4. Browser documents are intentionally shaped around each interactive tool and are not interchangeable with the `POST /api/generate` request body.

Use the HTTP contract on this page for deterministic remote generation. `design-sequence` is deliberately a bridge: it emits a compact, apply-ready compatibility document for programmatic browser rendering, and the browser normalizes it to current Studio source. For every other tool, use the active `window.glyphfield.studio` API to read/apply source or operate visible controls.

## Errors

Errors return `{ error: { code, field, message }, schemaVersion: 1 }`. Codes include `invalid_json`, `unknown_field`, `invalid_request`, `unknown_identity`, `invalid_identity`, `invalid_dimensions`, `pixel_limit`, `request_too_large` (413, body over 5,250,000 bytes), `unsupported_media_type` (415), and `generation_failed` (500). See [Errors and limits](/docs/agents/errors).
