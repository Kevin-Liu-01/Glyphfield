The reference pages list exact routes, actions, formats, limits and keyboard behavior. Use them when you already know the workflow and need a specific value.

- [Endpoint reference](/docs/reference/endpoints): every public HTTP route, its response and its errors.
- [Capability matrix](/docs/reference/capability-matrix): what each Studio tool can read, run and export.
- [Source format reference](/docs/reference/source-formats): the JSON source behind each tool.
- [Version compatibility](/docs/reference/version-compatibility): the version numbers and how migration works.
- [Studio Browser API](/docs/reference/browser-api): `window.glyphfield.studio` methods and actions.
- [Browser support](/docs/reference/browser-support): the browser features the Studio needs.
- [Self-hosting](/docs/reference/self-hosting): running your own deployment.
- [API security](/docs/reference/api-security): input limits, CORS and the production rate limit.
- [Troubleshooting and recovery](/docs/reference/troubleshooting): symptoms, causes and draft recovery.
- [Accessibility](/docs/reference/accessibility): keyboard use, reduced motion and accessible exports.
- [Keyboard shortcuts](/docs/reference/shortcuts): every shortcut in the Studio and the docs.
- [Social previews](/docs/reference/social-previews): the OpenGraph image routes and how crawlers reach them.
- [Licensing](/docs/reference/licensing): the MIT license and the material with its own terms.
