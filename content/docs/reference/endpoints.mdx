All routes are public and need no API key. Agent routes send these CORS headers:

```text
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type, Accept
```

`/openapi.json` describes every route below in OpenAPI 3.1.

## Discovery

| Method | Route | Response | Cache |
| --- | --- | --- | --- |
| GET | `/llms.txt` | Plain-text agent router | Static file |
| GET | `/llms-full.txt` | The complete documentation corpus as plain text, generated from the current MDX | `max-age=0, must-revalidate` |
| GET | `/api/docs/{slug}` | One processed documentation page as Markdown. `/docs/<path>.md` is rewritten to this route | `max-age=0, must-revalidate` |
| GET | `/api/agent` | The manifest: `{ name, version, schemaVersion, description, execution, interfaces, policies, resources, skills, studioBrowserApi, brand, generation }` | `max-age=300` |
| GET | `/openapi.json` | OpenAPI 3.1 document | |
| GET | `/api/catalog` | Studio tools, resource links, the Shader Library summary, and the deterministic surface library | None |
| GET | `/api/labs` | `{ categories, count, plugins, schemaVersion: 2 }`; each plugin is a Studio tool with `agentAccess`, `browserWorkspace`, and `capabilities` (`browserActions`, `browserApi`, `controlAutomation`, `directHttpGeneration`, `exports`, `sharedShaderLibrary`, `shaderFrameCapture`, `source`, `sourceEditing`) | `max-age=300` |
| GET | `/api/materials` | The Shader Library: `{ categories, kinds, shaderEffects, controls, count, defaults, engines, lookPresets, materials, framePersistence, palettes, schemaVersion, sharedBy, imageEffects }` | `max-age=300` |
| GET | `/api/identities` | `{ agentPresetField, identities, localIdentityPersistence, schemaVersion: 2 }` with the nine built-in `BrandIdentity` records | |
| GET | `/api/elements` | `{ categories, count, elements, generation, schemaVersion: 1 }` with the 89 brand elements | |
| GET | `/api/search` | Documentation search (Fumadocs and Orama) | |

`/api/materials` lists the materials the Shader Library shows. Retired materials are not listed, and image effects are listed separately under `imageEffects` (`{ categories, count, effects, requiresWebGPU, usage }`). See [Shader Library](/docs/studio/shader-library#http) for the material fields.

## Generation

| Method | Route | Content |
| --- | --- | --- |
| GET | `/api/generate` | The current contract (`schemaVersion` 3): request schema, kinds, identity forms, limits, and examples. Cached for 300 seconds |
| POST | `/api/generate` | Request `application/json`; response JSON, or `image/svg+xml` with `output: "raw"`. `Cache-Control: no-store` |
| OPTIONS | `/api/generate` | CORS preflight |

Kinds are `template` (the default), `background`, `element-brief`, and `design-sequence`. `design-sequence` returns a response-schema-1 envelope whose `document` is a version-3 compatibility source for Design Lab. Apply it with `applySource` in `/studio`; Design Lab normalizes it to CanvasDocument schema 2 with Design Lab source 4. Re-read the source, then export with `design.export`. See [Generation API](/docs/agents/generate).

Errors return `{ error: { code, field, message }, schemaVersion: 1 }`:

| Status | Codes |
| --- | --- |
| 400 | `invalid_json`, `invalid_request`, `unknown_field`, `unknown_identity`, `invalid_identity`, `invalid_dimensions`, `pixel_limit` |
| 413 | `request_too_large`: body over 5,250,000 bytes |
| 415 | `unsupported_media_type`: `Content-Type` is not JSON |
| 429 | Rate limit on the production deployment |
| 500 | `generation_failed` |

## Brand identity

| Method | Route | Content |
| --- | --- | --- |
| GET | `/api/brand/validate` | `{ description, endpoint, example, logoSlots, maximumRequestBytes, mergeRules, method, patchSchema, request, response, schema, schemaVersion }`: the BrandIdentity JSON Schema, the merge-patch schema, merge rules, and logo slots |
| POST | `/api/brand/validate` | Request `{ identity, mode?: 'full' \| 'patch' }` (default `full`); response `{ ok, issues, identity, health, schemaVersion }` |
| GET | `/api/brand/kit` | The kit contract and formats |
| POST | `/api/brand/kit` | Request `{ identity, format: 'dtcg' \| 'css' \| 'tailwind' \| 'markdown' }`; response is the file |
| OPTIONS | `/api/brand/validate`, `/api/brand/kit` | CORS preflight |

`POST /api/brand/kit` responds with `Content-Type: <type>; charset=utf-8` and `Content-Disposition: inline` with the file name `tokens.json`, `brand.css`, `tailwind.css`, or `brand.md`. The CSS and Tailwind files reference fonts at `../fonts/…`; the font files themselves come only from the browser action `identity.export.kit`, as do the ZIP and the logo pack.

Both routes are stateless: nothing is stored and no remote URL is fetched. Asset and font paths must be `data:` URLs or paths on the Glyphfield origin. Invalid source is not an HTTP error on `/api/brand/validate`: it returns `ok: false` with `issues[]`, each with a `path`, a `code`, and a `message`. `/api/brand/kit` returns `400 invalid_identity` naming the first invalid path. Both return `400 invalid_json`, `400 unknown_field`, `413` above 5,250,000 bytes, `415` for non-JSON, and `500 brand_request_failed`.

## Browser API

Every active Studio tool registers `window.glyphfield.studio` (version 1). It operates controls by accessible label, reads and applies source, runs tool actions, and downloads returned Blobs. See [Studio Browser API](/docs/reference/browser-api).

## Supporting routes

| Method | Route | Content |
| --- | --- | --- |
| GET | `/api/surface-textures/{assetId}/{map}` | One allowlisted CC0 surface map |
| GET | `/api/github-stars` | The repository star count for the site header |
| GET | `/api/og` | A 1200 × 630 PNG with `title`, `description`, `url`, and `accent` parameters ([Social previews](/docs/reference/social-previews)) |
| GET | `/api/og-home` | The home page's social image |
| GET | `/og/docs/{slug}/image.png` | A documentation page's social image |

`/api/surface-textures/{assetId}/{map}` accepts only the eleven asset IDs in the surface catalog and the maps `color`, `displacement`, `metalness`, `normal`, and `roughness`. It is not a URL proxy. Responses carry `X-Surface-License` and `X-Surface-Provider` and are cached (`max-age=86400, s-maxage=2592000, stale-while-revalidate=604800`). An unknown asset or map, or a missing map, returns `404`; an unreachable upstream returns `502`.

`/api/github-stars` is optional product chrome. Consumers must accept `503` with `stars: null`.

## Recommended discovery order

1. `/llms.txt`, then `/api/agent`
2. `/api/labs`
3. The task-specific catalog: `/api/materials`, `/api/identities`, `/api/elements`, or `/api/catalog`
4. `GET /api/generate` before an HTTP generation request
5. `/api/docs/{slug}` or `/llms-full.txt` for operating detail

Catalog IDs, schemas, and action lists are authoritative. The contract returned by `GET /api/generate` wins over prose in these docs.
