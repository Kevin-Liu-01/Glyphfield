Glyphfield is released under the [MIT License](https://github.com/Kevin-Liu-01/Glyphfield/blob/main/LICENSE). The license covers Glyphfield's source code and its original artwork, including the Starter identity's artwork under `public/templates`. It does not cover the assets bundled with the reference identities, the bundled font files, or third-party code and packages. Those keep their own terms.

## Glyphfield mark

The Glyphfield mark is a closed G whose crossbar is a lightning bolt that leaves through the G's mouth. It is original Glyphfield artwork. `public/brand/glyphfield-mark.svg` holds the dark version and `public/brand/glyphfield-mark-white.svg` the white version. The favicon (`src/app/icon.svg`) and the social preview images use the same drawing.

## Exported artifacts

An export contains whatever its composition uses. A file made with a reference identity can contain that brand's marks, pictures and fonts, and those keep their owners' terms. A file made with your own identity and Glyphfield's original artwork carries no Glyphfield restriction. A font embedded in an exported SVG keeps its own license. Lottie files from LottieFiles keep their individual licenses, so check each one before use.
