Every Studio tool has a JSON source document, accessible controls that the Browser API (`window.glyphfield.studio`) can operate through `controls()`, `activate()` and `set()`, and its own Browser API actions. `describe().capabilities` returns this record for the active tool, and `/api/labs` returns it for every tool.

The action counts leave out the six standard actions that every tool has: `source.read`, `source.apply`, `controls.list`, `control.activate`, `control.set` and `artifact.download`. [Studio Browser API](/docs/reference/browser-api) lists every action. The 2× PNG exports of the expression tools are capped at 4800 px on the longest edge.

The [Shader Library](/docs/studio/shader-library) is a shared material browser and is not a tool of its own. Design Lab, Animation, Lottie and the expression tools use it, and `/api/materials` publishes it. Deterministic [tactile backgrounds](/docs/studio/logo-background) come from `POST /api/generate` with `kind: "background"`.

## Output formats

| Format | Producers | Behavior |
| --- | --- | --- |
| SVG | HTTP templates and backgrounds, expression tools, Moodboard | Standalone files with the fonts and images embedded |
| PNG | Design Lab, Moodboard, Brand elements, expression tools, Lottie frame, Animation poster | Lossless still with transparency where the composition has it |
| JPG | Design Lab | Opaque still composited over the artboard background |
| GIF | Design Lab, Animation, Lottie | Palette-based motion without audio. Design Lab offers **Blended loop** or **Raw motion** |
| MP4 | Design Lab, Animation, Lottie | Encoded in the browser with H.264 tried first. Animation mixes in its audio |
| PDF | Brand book (print dialog), Slide templates (deck) | Brand book prints 16 × 10 in pages. Slide PDFs embed each page as a 2× image |
| HTML | Brand elements email elements | 600 px table layout with inlined styles |
| JSON | Brand identity, element briefs, project files, tool source, Lottie | Keep the schema versions, IDs and unknown fields |
| ZIP | Brand kit, logo pack | Stored without compression |
| `.lottie` | Lottie | The original archive |
| CSS, Tailwind, DTCG, Markdown | Brand kit, Color tokens, Typography | Written by the shared brand token serializers |
| TSX, HTML with CSS | Component library | Generated component code |

[Formats and portability](/docs/artifacts/formats-and-portability) explains each format in detail.

## Shared editing systems

| System | Behavior | Guarantee |
| --- | --- | --- |
| Color control | Swatch, HEX, OKLCH, hue, optional opacity and a screen eyedropper where the browser supports it | One normalized value feeds the preview and the export |
| Canvas viewport | Zoom, fit, reset, pan, and wheel or trackpad zoom | Zoom and pan do not change the artifact's geometry |
| Editable layers | Select, multi-select, drag, resize, nudge, snap | One transform drives the canvas, the source, saved designs and the export |
| Layer lists | Add, duplicate, hide, lock, reorder, group, align, delete | Layer order is serialized by ID, and each layer owns its opacity |
| Source drawer | **Apply code**, **Reset**, **Copy**, **Format**, find and replace | Valid source updates the same state as the controls |
| Saved designs | Named checkpoints and autosave | IndexedDB stores the document, and a small recovery journal covers page unload |
| Browser API | Controls, source, actions, downloads | It uses the same validators and renderers as the visible interface |

## Interface choice

- Use HTTP for deterministic artifacts that the generation contract fully describes, including batches.
- Use the Browser API for anything rendered with Canvas, WebGL or WebGPU, and for local files and browser codecs.
- Combine them when HTTP should author a Design Lab document and the browser should render it.

[Choose the right interface](/docs/agents/choose-interface) compares the two in more detail.
