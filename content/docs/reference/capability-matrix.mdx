## Shared editor capabilities

| System | Browser behavior | Persistence and output |
| --- | --- | --- |
| Color control | Native picker, HEX, OKLCH, optional opacity | Controlled value shared by previews and exports |
| Canvas viewport | Zoom from 40–200 percent, reset, and fit | Zoom saved per project and tool; intrinsic artifact ratio is unchanged |
| Canvas dimension handles | Drag width, height, or both directly on the Animation canvas | Output dimensions update the same persistent settings used by preview and GIF export |
| Shader gallery | Quality-sorted, searchable two-column live previews with source filters and badges | Shared catalog used by Material and Animation |
| Editable layers | Select, drag, resize, keyboard nudge | Transform values feed the same renderer used for export |
| Layer panel | Reorder, six-way alignment, reset, boundary-disabled actions | Layer order and transforms saved per project and template |
| Logo shader finishes | Reflections, shadows, outlines, glass, and presets | Finish object belongs to the independent logo shader layer |
| Uploaded assets | Logos, fonts, backgrounds, partner marks, Lottie JSON, and `.lottie` bundles | Sources remain local; supported exports embed resolved visual frames |
| Source drawer | Exact source editing with apply, reset, close, and inline validation | Applies into the same persistent tool state and renderer as visual controls |

## Browser-only reasons

Browser-only features depend on one or more of Canvas, WebGL, local font loading, object URLs, interactive visual placement, or multi-frame capture.

## API strengths

The API is best for repeatability, source-controlled SVG, batch generation, agent workflows, and downstream rendering pipelines.

The source drawer is not the HTTP request body for `/api/generate`. It is the active browser tool's document. See [Source format reference](/docs/reference/source-formats) before moving configuration between environments.
