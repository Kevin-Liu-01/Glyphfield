⌘ is the Command key on macOS; use Ctrl on Windows and Linux. Option is Alt on Windows and Linux. Shortcuts never act while a text field, select, or editable text has focus, unless they are text-editing shortcuts.

## Studio

| Shortcut | Action |
| --- | --- |
| ⌘K or / | Open **Search Studio tools** (/ only when no field has focus) |
| ↑, ↓, Enter, Escape | Move through tool results, open the selected tool, close search |
| F2 | Rename the focused project tab (your own projects only) |
| Option + ←, Option + → | Move the focused project tab left or right |
| Shift + F10 or the ContextMenu key | Open the menu of the focused project tab, layer, artboard, or canvas |
| Escape | Close open menus and popovers |

The letters shown beside tools in search results are visual hints and are not bound to keys.

## Canvas

These apply in every tool that uses the shared canvas viewport, while the canvas has focus or the pointer is over it.

| Shortcut | Action |
| --- | --- |
| ⌘Z | Undo |
| Shift + ⌘Z | Redo |
| Scroll | Zoom around the pointer |
| F | Fit canvas |
| + or =, − | Zoom in, zoom out |
| Drag on empty canvas | Pan |
| Arrow keys | Nudge the selected layer 1 px |
| Shift + arrow keys | Nudge 10 px |

## Design Lab

Press **?** or choose **Keyboard shortcuts** in the canvas toolbar to open the shortcut sheet in Design Lab. Escape closes it.

| Shortcut | Action |
| --- | --- |
| T, S, M, I, K, E | Add a text layer, shader layer, brand mark, image, sticker, or effect layer |
| ⌘C, ⌘X, ⌘V | Copy, cut, paste layers; with no layer selected, ⌘C copies the artboard |
| ⌘A | Select every unlocked layer on the active surface |
| Option + ⌘C, Option + ⌘V | Copy style, paste style |
| ⌘D | Duplicate the selection |
| Delete or Backspace | Delete the selection |
| ⌘] and ⌘[ | Bring forward, send backward |
| Shift + ⌘] and Shift + ⌘[ | Bring to front, send to back |
| ⌘G, Shift + ⌘G | Group, ungroup |
| Shift + ⌘L | Lock or unlock |
| Option + A, H, D | Align left, horizontal center, right |
| Option + W, V, S | Align top, vertical center, bottom |
| Option + Shift + H, V | Distribute horizontally, vertically |
| Space + drag, middle-button drag | Pan over content |
| ⌘B, ⌘I, ⌘U | Bold, italic, underline while editing text |
| Escape | Finish editing text; leave crop mode |
| Enter | Finish crop mode |
| ← and → on the focused Artboard map header | Dock the map left or right |

Design Lab keys work while the Design Lab has focus or the pointer is over it, and never while a text field, menu, or dialog has focus. Duplicate, delete, cut, and the order chords act on the canvas selection, or on the layer chosen in the layer list. Option shortcuts and the bracket chords read the physical key.

## Animation

| Shortcut | Action |

| Home, End | Move the storyboard playhead to the start or end |
| ←, → on the playhead | Step one output frame; with Shift, one second |
| ←, → on a trim handle | Move the cut one frame; with Shift, ten frames; with Option, ripple later scenes |

| Delete or Backspace on a keyframe diamond | Remove the keyframe |
| ←, → on the rotate handle | Rotate 1°; with Shift, 15° |
| ⌘ + scroll over the storyboard | Zoom the storyboard |
