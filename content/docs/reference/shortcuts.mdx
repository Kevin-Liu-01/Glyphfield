## Global Studio search

| Shortcut | Action |
| --- | --- |
| `⌘K` | Focus Studio search on macOS |
| `Ctrl+K` | Focus Studio search on Windows/Linux |
| `/` | Focus Studio search when not editing a field |
| `Escape` | Close open project and appearance popovers |

Typing in a text input, text area, or select prevents `/` from stealing focus.

## Documentation search

Fumadocs search uses `⌘K` or `Ctrl+K` while browsing `/docs`. Search indexes headings and body content across all documentation pages.

## Canvas

The canvas toolbar exposes zoom out, a zoom slider, reset to the original centered view, zoom in, and fit. Wheel or trackpad input over the workspace changes zoom. Dragging empty workspace pans the view. These controls use accessible names and can be reached with normal Tab navigation.

## Source drawer

The Code button, source text area, Apply, Reset, and Close actions follow normal Tab order and have accessible labels. Source editing does not currently reserve an Apply keyboard chord; use the explicit action so validation feedback remains visible.

## Tool labels

The single-character hints in the tool catalog are compact visual mnemonics. Global Studio search is the reliable keyboard route for selecting tools.
