`$glyphfield-brand` sets up the Brand identity tool, which holds the shared identity that every Glyphfield tool reads. The skill researches the brand from the user's website, repository or design files. It applies a validated identity through the Studio Browser API (`window.glyphfield.studio`), adds logo and font files, runs the brand health audit until no errors remain, and exports the brand kit.

## Example requests

- “Set up our brand in Glyphfield from acme.com and this repo.”
- “Fill the gaps the brand health audit found.”
- “Export brand.md and Tailwind tokens for this repository.”

## Procedure

1. Open the project at `/studio?tool=identity&project=<id>`. For a new brand, `identity.project.create { from, name }` creates and opens a project, with `from` set to `'starter'` or `'scratch'`. Read `window.glyphfield.studio` again afterwards. `identity.setup.prompt { mode }` returns the same prompt as **Set up with agent**.
2. Research the authorized sources and record each one in `sourceNotes`.
3. Draft a merge patch and check it with `identity.validate`. In the browser, patch validation merges the patch into the active identity, so it reports the same errors as `identity.apply` when no `replace` or `remove` option is used.
4. Apply the patch with `identity.apply`.
5. Add logos with `identity.asset.add { file, slot }` and fonts with `identity.font.add { file, roles, license }`.
6. Run `identity.audit`. Apply `identity.fix` or follow each finding's `agentPrompt`.
7. Call `identity.save`, then `identity.export.kit`, and check the returned Blob.

The skill uses only facts from authorized sources. It changes the identity only through `window.glyphfield.studio.invoke` and does not write browser storage. Files enter the Studio as `File` objects, and filesystem paths or remote URLs are not accepted. Combine the skill with [`$glyphfield-studio`](/docs/skills/studio) for other tools and [`$glyphfield-export`](/docs/skills/export) for files made from the brand. [Brand setup with an agent](/docs/agents/brand-setup) describes the full workflow.
