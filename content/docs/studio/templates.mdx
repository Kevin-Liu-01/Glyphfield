OpenGraph, Terminal card, Partnership lockup, Blog cover, and Slide templates share one editor and one document format. Each tool starts from a brand template built from the active identity: its colors, type roles, logos, graphic device, products, proof, and voice. Everything on the artboard is a layer that can be selected, moved, restyled, or removed.

## Type, spacing, and logos

Every template sizes type from one modular scale per format, with a ratio of 4:3. The body size is √(width × height) × 0.0176 for slides and × 0.0212 for social formats, because social images are read as thumbnails.

| Step | 1600 × 900 slide | 1200 × 630 social image |
| --- | --- | --- |
| caption | 16 px | 14 px |
| body | 21 px | 18 px |
| lead | 28 px | 25 px |
| subhead | 38 px | 33 px |
| headline | 50 px | 44 px |
| title | 67 px | 58 px |
| hero | 89 px | 78 px |

- **Tracking** follows the size: −0.022 em at title size and above, −0.018 em at headline, −0.014 em at subhead, −0.008 em at lead, and 0 at body and below. Uppercase text gets half these values. Code keeps 0. Template tracking is never positive; the inspector allows manual tracking from −10% to +20%.
- **Kerning** is on, with the `kern` feature, and the optical size axis follows the font size where the font has one. The canvas, the inline editor, SVG, and PNG use the same settings.
- **Slide titles**: a 16:9 title is 6–8% of the slide height per line. Headlines on content layouts stay at or below 6% of the height. Tests in `src/lib/__tests__/expressionType.test.ts` enforce these rules.
- **No labels above headlines.** Templates have no kicker, eyebrow, brand-name, or issue slots. Metadata such as the website, the page number, a metric's label, or a comparison side goes in the footer or after its content.
- **Logos** are sized by the ink they show. Bundled logo files carry a measured ink box, and a mark's height falls as its width grows (height ∝ aspect^−0.4), so a square monogram and a long wordmark carry similar weight.

## Edit on the canvas

- Click a layer on the canvas or in **Layers** to select it. Shift-click or ⌘/Ctrl-click adds layers. ⌘/Ctrl + A selects every unlocked layer. Escape clears the selection.
- Drag to move. Layers snap to the artboard edges and center and to other layers' edges and centers, with guides.
- Drag an edge or corner handle to resize. Rotate with the **Rotation** slider (±180°) or the ±15° buttons in the Layer section.
- Arrow keys nudge 1 px; Shift + arrow nudges 10 px.
- Double-click a text layer, or press Enter with it selected, to type on the canvas. Escape or a click outside finishes.
- Delete or Backspace deletes; ⌘/Ctrl + D duplicates; ⌘/Ctrl + ] and ⌘/Ctrl + [ move forward and backward, with Shift for front and back. Right-click opens the selection menu.
- ⌘/Ctrl + Z and Shift + ⌘/Ctrl + Z undo and redo. History keeps 120 steps; edits within 900 ms, such as a drag or a burst of typing, are one step.

**Layers** lists the stack top first. Drag a row by its handle, or focus it and press Alt + ↑ or ↓, to restack. Each row has **Hide** and **Lock** buttons. A locked layer cannot be moved on the canvas but stays editable in the inspector. The page background is a locked layer, so clicks on the page select content.

## Add layers

**Add** has **Add text layer**, **Add image layer** (from the identity library), **Add logo layer**, **Add shape layer**, **Add divider**, **Add shader background**, **Add texture layer**, **Add brand device**, and **Upload image layer** (a local file). Shader backgrounds and textures are inserted below the content. A shader background places the Shader Library's captured still of the chosen material, so the canvas and the export match.

Brand devices: `greetings` (Language field), `beam` (Knowledge beam), `waves` (Utility wave), `ledger` (Savings ledger), `horizon` (Network horizon), `convergence` (Convergence field), `field` (Programmable field), `window` (Focus window), `interruption` (Engineered interruption).

| Shader | Material from the compact Shader Library (12 cards) and **Tint** (Original colors or Brand duotone) |
| Texture | Grid, dots, lines, diagonal, or noise; spacing 4–160 |

Colors are brand roles (Ink, Paper, Emphasis, and the identity's other colors) or a custom color. Roles stay linked to the identity, so changing an identity color updates every layer that uses it.

## Layouts

`Layout <name>` re-flows the layers a template placed. Text, uploads, and styles set by hand stay. Content a layout has no slot for is kept and returns when you switch back. **Reset to brand template** starts over from the identity's template.

## Export

| Action | Result |
| --- | --- |
| **Export PNG** | The artboard, or the active slide, rendered as SVG and rasterized at 2×, with the long edge capped at 4800 px |
| **More exports → Export SVG** | A self-contained SVG with images and font files embedded |
| **More exports → Export PDF deck** | Slides only: every slide in one PDF |

PNG and SVG files are named `studio-<tool>.png` and `.svg`; slide exports add the slide number. Exports render from the same document as the canvas.

## Source format

Each tool stores a CanvasDocument schema 2 with expression source version 2. Pages are artboards (one per slide), elements are layers with a `data.slot` role and brand color roles, and `metadata.studio` holds `{ sourceVersion: 2, toolId, state }`. `state` holds the format, each page's layout, surface, and stash of layout content, and flat `title`, `body`, `code`, and `language` fields that mirror the first page's headline, list or supporting copy, and code. Editing the flat fields in source still works.

Applying source rejects a document of another tool or kind, or one with a newer `sourceVersion`. Text layers need a `textStyle` and code layers at least one tab. Embedded library assets are re-pointed to the identity's files. Version-1 sources (flat tool state from before the shared editor) migrate on open. See [Source formats](/docs/reference/source-formats).

## Browser API

Every tool registers these actions, where `{tool}` is `opengraph`, `terminal`, `partnership`, `blog`, or `slides`:

| Action | Input | Output |
| --- | --- | --- |
| `{tool}.document.describe` | None | `{ format, formats, layouts, activePageId, selection, pages: [{ id, name, layout, surface, width, height, notes, layers }] }`; layers are top first with id, kind, slot, bounds, visibility, and lock |
| `{tool}.layer.add` | `{ kind: 'text' \| 'image' \| 'logo' \| 'shape' \| 'divider' \| 'shader' \| 'texture' \| 'device', content?, bounds?, fill?, libraryAssetId?, dataUrl?, materialId?, device?, shape?, variant? }` | `{ id }` |
| `{tool}.layer.update` | `{ id, name?, content?, bounds?, opacity?, hidden?, locked?, fill?, fontRole?, fontSize?, fontWeight?, letterSpacing?, lineHeight?, align?, casing?, radius?, data? }` | `null` |
| `{tool}.layer.remove`, `{tool}.layer.select` | `{ ids }` | `null` |
| `{tool}.layer.duplicate` | `{ ids }` | `{ ids }` |
| `{tool}.layer.reorder` | `{ id, to: 'forward' \| 'backward' \| 'front' \| 'back' \| number }` | `null` |
| `{tool}.layer.align` | `{ ids, alignment }` | `null`; aligns to the artboard |
| `{tool}.format.set` | `{ format }` | `null` |
| `{tool}.layout.apply` | `{ layout, pageId? }` | `null` |
| `{tool}.template.reset` | None | `null` |
| `{tool}.history.undo`, `{tool}.history.redo` | None | `true`, or `false` when there is nothing to undo or redo |
| `{tool}.export.png`, `{tool}.export.svg` | None | Export artifact of the active page |

Read `document.describe` first; it returns the layer IDs, slots, formats, and layouts the other actions take. Each tool page lists its extra actions.

```js
const studio = window.glyphfield.studio;
const doc = await studio.invoke('opengraph.document.describe');
const headline = doc.pages[0].layers.find((layer) => layer.slot === 'headline');
await studio.invoke('opengraph.layer.update', { id: headline.id, content: 'Ship every locale', fontRole: 'Display' });
await studio.invoke('opengraph.format.set', { format: 'square' });
const png = await studio.invoke('opengraph.export.png');
```

## HTTP

`POST /api/generate` with `kind: "template"` renders the same brand templates as standalone SVG with the brand fonts embedded. `template` is `slides` (the default), `blog`, `partnership`, `opengraph`, or `terminal`, with optional `layout` (or `slideLayout` for slides), `format`, and `language`. It renders one page. See [Generation API](/docs/agents/generate#templates).

## Limits

- PNG export at 2×, long edge at most 4800 px.
- Font weights 100–550 in the inspector.
- History keeps 120 steps.
- Fonts embedded in HTTP SVG are skipped when a font's data URL exceeds 560,000 characters.
