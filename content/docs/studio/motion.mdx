Glyphfield has three tools that produce motion. They share the [Shader Library](/docs/studio/shader-library), its palettes, and its material time model, and they export through the same browser GIF and MP4 encoders.

| Need | Tool |
| --- | --- |
| A sequence of text, logo, and image scenes with transitions, keyframes, text entrances, captions, and audio | [Animation](/docs/studio/animation) |
| Playback, editing, recoloring, and trimming of a Lottie JSON or `.lottie` file | [Lottie](/docs/studio/lottie) |
| A layered poster whose shaders move, or a clip that cuts through several shaders | [Design Lab](/docs/studio/design-lab) |
| Choosing and tuning a live material | [Shader Library](/docs/studio/shader-library) |

## Compare the tools

| | Animation | Lottie | Design Lab |
| --- | --- | --- | --- |
| Input | Text frames, the brand mark, local images, audio files | Built-in studies, local `.lottie` or JSON | Layers on artboards |
| Timing | Per-scene hold and outgoing transition on a storyboard, layer keyframes | The Lottie file's frames, in and out points, markers, speed, direction | Shader time; optional shader sequence of 8–12 cuts |
| Background | Solid, gradient, or a Shader Library material for the whole sequence, with per-scene overrides | Transparent, solid color, or a live material | Any number of shader layers |
| Exports | GIF, MP4 with audio, PNG poster frame, project file | PNG frame, GIF, MP4, edited JSON or the original `.lottie` | PNG, JPG, GIF, MP4, shader-sequence GIF and MP4, project file |
| Frame rates | 10, 15, 20, 24, 30 FPS | GIF 25 FPS, MP4 30 FPS | 12, 15, 24, 30, 60 FPS |
| Audio | Yes, MP4 only | No | No |
| Browser API | `animation.*` | `lottie.*` | `design.*` |

## Shared rules

- Exports run one at a time, because the canvases and encoders are shared.
- GIF has no audio channel.
- MP4 needs a browser video encoder. Glyphfield prefers H.264 and reports a missing encoder instead of substituting GIF.
- Stateful materials, such as Fluid Energy and the interactive Shaders.com materials, cannot be reproduced from a time value. Animation refuses to export a stateful background; Design Lab exports exact stills of them but refuses timestamp-sampled motion.
- A continuous animation clock is not a seamless loop. Inspect several frames and the seam of every looping file.
- The Studio respects `prefers-reduced-motion`, and **Reduce motion** in Visual settings pauses decorative effects. Exports are explicit actions and always contain the requested motion.
