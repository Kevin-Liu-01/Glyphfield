Glyphfield includes three focused motion systems: frame-based Animation, a dedicated Lottie editor, and Material for live WebGL motion.

## Animation

Animation combines text, identity logos, and imported images in one reorderable sequence. The GT example begins with the real GT mark before morphing into its multilingual greetings. Its three-column workspace keeps sources and layer order on the left, the shared canvas and timeline in the center, and frame, material, easing, timing, and export properties on the right. Select any state to tune its position, scale, rotation, opacity, typography or image fit without changing the rest of the sequence.

Open **Code** to edit the exact animation configuration as JSON. The source includes the source mode, newline-delimited text frames, logo inclusion, sequence order, global settings, per-frame settings, and playback rate. Applying valid source updates the timeline and canvas immediately; invalid fields remain in the drawer with an error and never replace the active animation.

## Lottie

Lottie is a separate Motion tool with its own vector playback model. Import a local `.lottie` bundle or Lottie JSON document, or begin with the Orbit, Signal, and Geometric Fold examples. Its source library sits to the left of the canvas; playback, appearance, and live-material properties remain visible in the right inspector.

The editor includes play, pause, restart, scrubbing, speed, forward/reverse/bounce modes, looping, interpolation, in/out trimming, contain/cover/fill layout, transparent or solid canvases, and high-resolution frame export. Generic JSON artwork can be recolored directly. `.lottie` bundles retain embedded colors unless they provide their own named themes.

The Lottie canvas can remain transparent, use a flat brand color, or use the same live material engine and brand-first palettes as Animation, Material, and Surface Lab. Frame PNG export composites the vector frame over that live background at the selected output size. Download the edited JSON or original `.lottie` bundle at any time. The LottieFiles link is a discovery route, not a mirrored marketplace: verify the license on the individual animation before using or distributing it. Imported files remain in the browser.

The source drawer exposes raw Lottie JSON for documents that can be represented as text. Apply requires a JSON object with a `layers` array and numeric `fr` frame rate. A `.lottie` bundle is a binary archive, so Glyphfield preserves and downloads that original bundle instead of presenting it as editable JSON.

## Animation details

The canvas uses direct manipulation: selecting a state pauses on that frame, dragging moves it, arrow keys nudge it by one canvas pixel, Shift + arrow nudges by ten, and the corner handle scales it. Inspector values and canvas gestures update the same persisted frame data.

Each state also owns its background. Choose a solid color, two-color gradient, or any live ShaderGradient/Shaders.com-inspired material, then transition between state backgrounds with a crossfade, directional wipe, or radial reveal. Shader colors, speed, strength, frequency, grain, and material are editable in the same frame inspector.

### Animation packages

- Morph fade
- Type and delete
- Crossfade
- Scale fade
- Slide fade

Type and delete reveals and removes real characters without a cursor. Morph fade uses blur, opacity, and scale rather than a collapsing vertical wipe, and works across text-to-text, text-to-image, image-to-text, and image-to-image transitions.

### Timing

Control hold time, transition time, playback speed, frame rate, loop, and a cubic Bézier curve. Presets include material, snappy, soft, and dramatic curves.

The playhead is deterministic: preview and export resolve from the same timing model. Alignment guides indicate the configured horizontal and vertical center.

### GIF output

Choose canvas dimensions, frame rate, palette colors, per-frame fit and scale, then select **Export GIF**. Email, HD, and 2× presets are included. New and migrated projects default to the GIF format’s full 256-color palette with RGB565 quantization. The export composites the same text, image, logo, background transitions, gradients, and live shader canvases used by the preview. Larger canvases, more frames, higher frame rates, live materials, and larger palettes increase encoding time and file size.

The same per-frame preparation hook is the basis for Glyphfield's general HTML/canvas-to-GIF pipeline: a source resolves its visual state at an exact timeline position, then the shared renderer captures that state.

## Material

Material applies live WebGL motion to the background, the alpha-masked logo, or both. It lives beside Animation in the Motion section so shader work has a focused workspace while Surface Lab remains dedicated to backgrounds and logo applications.

The material engine includes:

- The editable ShaderGradient sphere preset, including three colors, environment brightness, amplitude, density, frequency, strength, grain, rotation, and speed.
- Ten original local GLSL recipes for the public material techniques documented by Shaders.com: Pixel Beams, Soft Register, Spectral Bloom, Pistons, Fluid Chrome, Chroma Flow, Drift, Mosaic, Circuit, and Dedalus Bloom.
- Studio GLSL presets including liquid metal, mercury, brushed steel, aurora, topographic, plasma, radial beams, halftone, warped grid, glass waves, iridescent, heatmap, gem smoke, and grain gradient.
- A local custom GLSL editor using the same time, resolution, color, and material uniforms.

Every material color accepts HEX or OKLCH input, and the eight included combinations provide considered monochrome, mercury, ultraviolet, signal, copper, arctic, vermilion, and cobalt starting points. PNG and GIF export use the same live canvas visible in the preview.

Control the material colors, distortion parameters, speed, aspect ratio, logo placement, scale, opacity, and transparent output. Upload a transparent PNG or SVG to replace the identity mark for the current session.

Open **Code** to edit the complete material configuration, including engine, target, aspect ratio, export quality, colors, logo, parameters, live settings, finish, speed, preset identifiers, and custom GLSL. The drawer and visual inspectors resolve into the same renderer, so a source edit can be refined visually without conversion.

### Shader output

- Download PNG for a still frame.
- Download GIF to capture the animated material at 20 fps with a 256-color palette.
- Choose Standard, High, or Ultra output dimensions; High is the default and PNG remains lossless.
- Transparent logo output preserves alpha when the selected target supports it.

WebGL and GIF capture are browser-only capabilities. Agents should open `/studio` when they need these outputs.
