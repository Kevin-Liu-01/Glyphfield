Animation (tool ID `animation`) is a sequence editor for brand motion. Each scene holds one layer (text, the brand mark, or an image) over a background. Each scene owns its hold duration, its outgoing transition, its pose and keyframes, and an optional text entrance and caption. Backgrounds are shared by the sequence unless a scene overrides them.

## Brand starters

A first visit opens on the identity's **Brand intro**. **Brand starters** offers three sequences for every identity, each composed in that identity's art direction on a 1280 × 720 artboard:

| Starter | ID | Scenes |
| --- | --- | --- |
| Brand intro | `brand-intro` | The mark, then up to six greetings |
| Product reel | `product-reel` | Up to four products, then the mark |
| Proof points | `proof-points` | Up to three proof points, then the mark |

Each identity keeps its own field, type, accent, cadence, and captions. General Translation keeps its centered 1.25-second morph on black and names each language in the corner. Display weight and tracking come from the identity's Display role; captions use its Code face. Applying a starter replaces the active artboard and resizes it to 1280 × 720; **Undo** restores the previous sequence. Saved drafts are never replaced on load.

## Scenes and layers

**Add animation layer** has **Text**, **Image** (one or more local image files), **Base** (the base background), and **Transition**. The **Brand mark** checkbox includes or removes the mark scene. Each scene row has `Move <scene> up`, `Move <scene> down`, `Remove <scene>`, and `Use base background for <scene>`. Source order, timeline order, preview, and export stay in sync.

New text scenes start black in light mode and white in dark mode, including when added through Browser API controls. The color is saved on the scene; changing the Studio theme does not recolor existing scenes, images, or backgrounds.

## Edit a scene

Select a scene on the storyboard or in the scene list. The inspector shows:

| Section | Controls |
| --- | --- |
| Content | Text, or **Image fit** (Contain or Cover) for images |
| Pose | **Horizontal** and **Vertical** −1 to 1, **Scale** 0.1–2.5, **Rotation** −180° to 180°, **Opacity** 0–100% |
| Align | **Align layer left**, center, right, top, middle, bottom (to the safe area, 8% of the shorter side), **Show layout guides** |
| Type | **Anchor** (Centre or Leading edge), **Text size**, **Weight** 100–550, **Text color** |
| Caption | Text scenes: up to 120 characters at top-left, top-right, bottom-left, or bottom-right |
| Timing | **Scene duration** 100–10,000 ms |
| Text entrance | Text scenes: preset, **Entrance duration** 100–3000 ms, **Stagger** 0–300 ms (0 is Auto; Word rise and Glyph stagger), **Entrance easing** |
| Keyframes | **Motion presets**, **Add keyframe at playhead**, **Clear keyframes**, and one row per keyframe with time, easing, **Go to keyframe N**, and **Remove keyframe N** |
| Effects | Text effects or artwork finish |

On the canvas:

- Drag to move. Moves snap to the canvas edges and center lines. Arrow keys nudge 1 px, or 10 px with Shift.
- Drag the round handle above the layer to rotate. Shift snaps to 15°. With the handle focused, ← and → rotate by 1°, or 15° with Shift.
- **Show layout guides** shows thirds and the safe area. Guides are never exported.
- **Anchor** sets whether text hangs from its center or its leading edge. A leading-edge anchor keeps a left-aligned headline on its margin when the words change.
- A caption is one small line of scene metadata (an index, a language name, a command) in the Code face at a corner of the safe area. Captions stay fixed and exchange by opacity during transitions.

Dragging, scaling, and rotating on the canvas update the same scene data as the inspector. The layer follows a drag live and commits once on release.

### Keyframes

Keyframes animate the layer's horizontal and vertical position, scale, rotation, and opacity across the hold. Each keyframe stores a full pose and the easing of the segment that leaves it: Material, Ease out, Ease in-out, Overshoot, or Linear.

1. Select the scene and choose **Add keyframe at playhead**.
2. Move the playhead within the scene, then move, scale, or rotate the layer. Once a layer has keyframes, an edit updates the keyframe at the playhead or inserts one there.
3. Set each keyframe's easing in the keyframe list.

Keyframes appear as diamonds on the storyboard. Drag a diamond, or press ← or → (ten frames with Shift), to retime it; Delete or Backspace removes it. Removing the last keyframe keeps its pose as the static pose. Before the first keyframe and after the last, the nearest pose holds. During a transition the outgoing scene leaves from its last pose and the incoming scene enters from its first.

**Motion presets** replace the keyframes with a preset built around the settled pose: **Push in** (scale × 1.06 across the hold), **Rise in** (from 0.14 lower and transparent), **Slide in** (from 0.22 to the left), **Pop in** (from 82% scale within 520 ms), and **Float** (a small drift at mid-hold).

### Text entrances

| Entrance | Behavior |
| --- | --- |
| Type on | Graphemes appear one at a time, without a cursor |
| Word rise | Words fade and rise one after another |
| Line reveal | The line rises out of a baseline mask |
| Glyph stagger | Each glyph settles from below in sequence |
| Tracking in | Wide letterspacing closes to the set width |

Entrances use the scene's display face and metrics. The default is 640 ms with ease out. Entrances and keyframes render the same in the preview, GIF, MP4, and the poster frame.

## Transitions

Select a transition on the storyboard to edit the cut out of a scene:

- **Background blend**: Crossfade, Directional wipe, or Radial reveal.
- **Cut duration**: 0–2000 ms; **Use sequence duration** removes the override.
- A package from the gallery: Morph fade, Type / delete (text only), Crossfade, Scale fade, Slide fade, Rise fade, Zoom through, Blur swipe, Flip fade, Spring pop, Rotate fade, Drift fade.
- Easing: material, snappy, soft, or dramatic, or a cubic Bézier curve with X1, Y1, X2, Y2 fields (X 0–1, Y −1 to 2).
- **Use sequence transition** removes the override.

These settings are stored on that scene's outgoing transition, not on the whole sequence. Type / delete reveals and removes real characters without a cursor. Morph fade uses blur, opacity, and scale, and works between text and image scenes in any combination.

## Storyboard

| Control | Action |
| --- | --- |
| **Play preview** / **Pause preview**, **Restart preview** | Transport |
| **Previous frame**, **Next frame** | Step one output frame |
| **Timeline playhead** | Scrub. With the storyboard playhead focused: Home, End, ← and → (one frame), Shift + ← and → (1 second) |
| **Zoom timeline out**, **Zoom timeline in**, **Fit timeline to view** | 40–800 px per second, 1.25× per step; or ⌘/Ctrl + scroll |
| **Playback rate** | 0.1×, 0.25×, 0.5×, 1×, 2×, 4× |
| `Scene N duration` handle | Drag the end of a hold to trim. Default is roll: the next scene absorbs the change. Alt ripples later scenes. ← and → move one frame, Shift ten. Trims snap to output frames; the minimum hold is 100 ms |

During playback the scene list and inspector follow the current scene. Pause or scrub to a hold to edit that scene, or inside a transition to edit the transition. The storyboard scrolls with playback; manual scrolling pauses following for 1.5 seconds. Storyboard zoom is a view setting and never changes timing.

## Backgrounds

The sequence has one base background, **Base background — Behind every scene**: a solid color, a two-color gradient, or a material from the [Shader Library](/docs/studio/shader-library). In the background inspector, **Background scope** chooses **Sequence** (changes update every scene that follows the sequence background) or **Frame** (the next change creates an override for this scene). **Use sequence background** removes one override; **Make all frames follow sequence** removes all of them.

Shader time follows the animation playhead, so scrubbing shows the material frame that export captures. Pausing the sequence pauses the material. Shader zoom uses the same 0.1×–10× logarithmic scale as Design Lab.

## Audio

**Choose audio files** imports browser-decodable audio. Clips sit on the audio track below the storyboard with **Timeline**, **In**, and **Out** positions in seconds, **Split** (at the playhead), a clip level, and **Delete selected audio clip**. **Mute audio** and **Master audio volume** apply to the whole track. Clips must be at least 100 ms long. The waveform is decoded locally. MP4 export mixes overlapping clips; GIF has no audio.

## Artboards

The artboard bar has the active artboard picker, **Set artboard size** (the Design Lab presets plus custom sizes from 120 to 4096 px), **Add animation artboard**, **Duplicate animation artboard**, and **Delete artboard**. The stage's edge and corner handles resize the output from 120 × 120 up to 3200 × 2400 in 10 px steps. Zoom changes only the view.

## Saving

Working drafts autosave. **Save checkpoint** creates a named checkpoint and **Save changes** updates it. **Saved animations** lists checkpoints, marks the **Current** one, and offers **New blank animation**, **Save as independent copy** (Clone), **Save as linked copy** (Fork), **Rename**, and **Delete** with confirmation. Undo and Redo cover sequence edits, scene settings, images, and artboards. Checkpoints stay in this browser; use a [project file](/docs/studio/project-files) to share or back them up.

## Export

| Format | Details |
| --- | --- |
| GIF | Deterministic frame times at the Output frame rate; delays are rounded to 10 ms, so 24 FPS plays as 40 ms frames. One global palette sampled from up to 8 frames, with up to 16 text colors protected. Still holds collapse to one frame unless a shader, keyframe, or entrance moves. Loop forever sets the loop flag. No seamless-loop blending |
| MP4 | Encoded in the browser with H.264 first, then any other MP4 codec. A keyframe every 2 seconds. Includes the mixed audio track. Fails with an error when no encoder is available |
| PNG poster | **File → Export poster frame**: the frame at the playhead at full output size |
| Project file | **File → Download project file**: a `.glyphfield.json` file with artboards, scenes, timing, backgrounds, and embedded image, audio, and font bytes |

Files are named `studio-<package>.gif`, `studio-<package>.mp4`, and `studio-<package>-<ms>ms.png`. Export is refused when the background is a stateful material, such as Fluid Energy, because its frames cannot be reproduced from time. Larger sizes, more frames, and live materials increase export time.

## Source format

The source is a CanvasDocument schema 2 with `metadata.tool: "animation-studio"`. `metadata.animation` holds `mode`, `textFrames`, `includeBrandLogo`, `sequenceOrder`, `settings`, `frameSettings` (per scene: `holdMs`, `transitionMs`, `transition`, `keyframes`, `textAnimation`, `caption`, `textAnchor`, `tracking`, pose, and background override), `sequenceBackground`, `backgroundOverrides`, `playbackRate` (greater than 0, at most 4), `audio`, `artboards`, `activeArtboardId`, and an optional `identity` typography snapshot. Validation rejects malformed motion fields with their path, for example `frameSettings.text-0.keyframes[1].atMs must be a finite number.`

## Browser API

| Action | Input | Output |
| --- | --- | --- |
| `animation.describe` | None | `{ durationMs, fps, width, height, playheadMs, scenes: [{ id, index, kind, label, startMs, holdMs, transitionMs, keyframes, textAnimation }], starters }` |
| `animation.seek` | `{ timeMs }` | `animation.describe` result; pauses first |
| `animation.scene.update` | `{ sceneId, holdMs?, transitionMs?, textAnimation?, pose? }`; `null` resets a value to the sequence default or removes the entrance | `animation.describe` result |
| `animation.keyframe.set` | `{ sceneId, atMs, pose?, easing?: [x1, y1, x2, y2] }` | `animation.describe` result |
| `animation.keyframe.remove` | `{ sceneId, keyframeId }` | `animation.describe` result |
| `animation.motion.preset` | `{ sceneId, preset: 'push-in' \| 'rise-in' \| 'slide-in' \| 'pop-in' \| 'float' }` | `animation.describe` result |
| `animation.starter.apply` | `{ starterId: 'brand-intro' \| 'product-reel' \| 'proof-points' }` | `animation.describe` result |
| `animation.export` | `{ format: 'gif' \| 'mp4' \| 'png', download? }` | Export artifact |
| `animation.export.gif`, `.mp4`, `.png`, `.project` | None | Export artifact |

`textAnimation.preset` is `none`, `type-on`, `word-rise`, `line-reveal`, `glyph-stagger`, or `tracking-in`. Pose fields are `alignX`, `alignY`, `scale`, `rotation`, and `opacity`. Each must be a finite number and is clamped to the range saved keyframes use: `alignX` and `alignY` −1.5 to 1.5 (±1 is the canvas edge), `scale` 0.05 to 8, `rotation` −720° to 720°, and `opacity` 0 to 1.

```js
const studio = window.glyphfield.studio;
let animation = await studio.invoke('animation.starter.apply', { starterId: 'product-reel' });
const [first] = animation.scenes.filter((scene) => scene.kind === 'text');
await studio.invoke('animation.scene.update', {
  sceneId: first.id,
  holdMs: 1800,
  textAnimation: { preset: 'word-rise', durationMs: 640 },
});
await studio.invoke('animation.motion.preset', { sceneId: first.id, preset: 'push-in' });
await studio.invoke('animation.keyframe.set', { sceneId: first.id, atMs: 900, pose: { alignY: -0.05 } });
animation = await studio.invoke('animation.seek', { timeMs: first.startMs + 1200 });
const poster = await studio.invoke('animation.export.png');
```

The labels **Scale** and **Text size** exist both in Sequence defaults and in the scene inspector. `studio.set('Scale', …)` changes the first match, the sequence default; use `animation.scene.update` for a scene's pose.

## HTTP

Animation has no HTTP generation route. Identity colors and fonts come from the active project.
