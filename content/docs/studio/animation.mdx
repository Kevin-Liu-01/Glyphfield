Animation is a sequence editor for brand motion. Each scene holds one layer (text, the brand mark, or an image) over a background. Every scene owns its duration, its outgoing cut, its pose and keyframes, and an optional text entrance and caption, while inheriting or overriding the composition background.

## Brand starters

A first visit to Animation opens on the identity's **Brand intro**: the mark, then its greeting words, in a 1280 × 720 artboard composed in that brand's art direction. **Sequence layers → Brand starters** offers three story shapes for every identity:

- **Brand intro**: the mark, then the identity's greetings.
- **Product reel**: one scene per product, closing on the mark.
- **Proof points**: the identity's proof set large, closing on the mark.

Each identity keeps its own field, type, accent, cadence, and metadata device. Ramp sets light Lausanne on paper with one lime scene; Stripe sets Söhne over a blurple mesh; Vite+ captions each scene with its `vp` command; General Translation keeps its centred 1.25 s morph on exact black and names each language in the corner. Display weight and tracking come from the identity's Display typography; the scene captions use its Code face. Applying a starter replaces the active artboard; **Undo** restores the previous sequence. Existing drafts and autosaved animations are never replaced on load.

New text frames start black in light mode and white in dark mode, including when added through Browser API controls. The color is saved on the new frame; changing the UI theme does not recolor existing frames, imported artwork, backgrounds, or reopened projects.

## Choose the source mode

- **Sequence** mixes brand marks, text, and imported images in one ordered timeline.
- **Text** builds a text-only sequence from newline-separated frames.
- **Images** creates motion from authorized local image files.

Start with the brand logo when the motion should establish identity before language or product content. Reorder states from the source list; timeline order, source order, preview, and export stay synchronized.

## Frame composition

Select a scene to edit its content, duration, entrance, keyframes, position, scale, rotation, opacity, caption, anchor, and background. Dragging, scaling, and rotating on the canvas update the same frame document used by the inspector; the canvas content follows a drag live and commits once on release.

- **Rotate** with the round handle above the layer. Shift snaps to 15°; Left and Right arrows rotate by 1° (Shift: 15°).
- **Move** by dragging or with the arrow keys (1 px; Shift: 10 px). Moves snap to the canvas edges and centre lines.
- **Align** with the six safe-area buttons in the inspector: left, centre, right, top, middle, bottom. The safe area is 8% of the shorter side.
- **Show layout guides** overlays thirds and the safe area on the stage. Guides are view-only and never exported.
- **Anchor** sets whether text hangs from its centre or its leading edge. A leading-edge anchor keeps a left-aligned headline on its margin when the words change.
- **Caption** adds one small line of scene metadata (an index, a language name, a command) in the identity's Code face at a corner of the safe area. Captions stay fixed in the frame and exchange by opacity during cuts.

### Timing and the storyboard

Every scene has its own duration and outgoing cut. Scenes without an override follow **Sequence defaults → Frame duration** and **Transition duration**. Set a scene's length under **Timing → Scene duration**, or select a cut and set **Cut duration**; **Use sequence duration** removes the override.

The storyboard lays scenes out in proportion to their time. Drag the edge at the end of a scene's hold to trim it. A trim rolls the cut by default: the next scene absorbs the change, so later scenes keep their place on the master timeline. Hold **Alt** while dragging (or with the arrow keys) to ripple instead and shift every later scene. With the trim handle focused, Left and Right move the cut by one output frame, Shift by ten.

Zoom the storyboard with **Zoom timeline in** and **Zoom timeline out**, **Fit timeline to view**, or Ctrl/Cmd + scroll over the storyboard. Zoom is a view setting per brand; it never changes timing.

### Layer keyframes

Keyframes animate a scene layer's horizontal and vertical position, scale, rotation, and opacity across its hold. Each keyframe stores a full pose and the easing of the segment that leaves it.

1. Select the scene and choose **Add keyframe** to capture the pose at the playhead.
2. Move the playhead within the scene, then move, scale, or rotate the layer on the canvas or in the inspector. Once a layer has keyframes, an edit updates the keyframe at the playhead or inserts a new one there.
3. Choose each keyframe's easing (material, ease out, ease in-out, overshoot, linear) in the keyframe list.

Keyframes appear as diamonds on the storyboard. Drag a diamond or use Left and Right (Shift: ten frames) to retime it; Delete removes it. Removing the last keyframe keeps its pose as the scene's static pose. **Motion presets** build keyframes around the settled pose in one click: **Push in**, **Rise in**, **Slide in**, **Pop in**, and **Float**. Before the first keyframe and after the last, the nearest pose holds. During a cut the outgoing scene leaves from its last pose and the incoming scene enters from its first.

### Text entrances

A text scene can play an entrance at the start of its hold, set in the scene's own brand display face and measured with the same metrics as the static frame:

| Entrance | Behaviour |
| --- | --- |
| Type on | Graphemes appear one at a time, without a cursor. |
| Word rise | Words fade and rise one after another. |
| Line reveal | The line rises out of a baseline mask. |
| Glyph stagger | Each glyph settles from below in sequence. |
| Tracking in | Wide letterspacing closes to the set width. |

Set the entrance duration, the stagger for word and glyph entrances (Auto spreads units across half the entrance), and its easing. Entrances and keyframes render identically in preview, GIF, MP4, and the poster frame; GIF samples every frame of a hold that moves and keeps a single frame for still holds.

During playback, the scene highlights and inspector follow the current scene. Pause or scrub to a hold to edit that displayed scene; pause or scrub inside a transition to inspect the transition instead. Canvas selection boxes stay hidden during playback and transitions. Selecting a scene background or the base background keeps that explicit editing target.

The bottom storyboard scrolls horizontally with playback, keeping the playhead and upcoming frames in view. It follows back to the start when playback loops. Manual scrolling and timeline drags temporarily suspend following; it resumes after 1.5 seconds of inactivity or when you press Play again. Paused browsing stays put, while an explicit seek reveals the requested time. This behavior is shared by the landing demo and the full Studio.

The stage exposes edge and corner handles for output width and height. This changes the exported composition itself; the zoom toolbar changes only the view.

**Artboard setup** shares its presets with Design Lab, including a portrait row for **3:4** (1080 × 1440), **2:3** (1080 × 1620), and **1:2** (1080 × 2160). Choose a preset or enter custom dimensions; source, saved artboards, and export use the same width and height.

The tool header keeps **Save checkpoint**, **Saved animations**, save state, **File**, and exports together. Open **Saved animations** for **New blank animation**, **Save as independent copy** (Clone), and **Save as linked copy** (Fork). Working drafts autosave; named checkpoints are explicit. **File** groups **Open project file**, **Download project file**, and **Edit source code**. The cloud indicator and saved-animation library use distinct icons. A compact **Error** button opens complete failure details by click or keyboard without adding a strip below the canvas.

The artboard bar stays focused on the current animation: the artboard picker and size settings sit on the left; add, duplicate, and delete sit on the right. Undo, Redo, and Action history remain together in the canvas dock.

Canvas Undo and Redo restore sequence edits, frame settings, images, and artboards. Saved animations are separate named checkpoints: save a version, rename it in Saved animations, or reopen an earlier checkpoint without treating every edit as a new saved file. Text follows the active brand's Display font; General Translation uses Inter by default.

**Saved animations** uses the same picker as Design Lab. The **Current** row closes the picker without reloading saved content over your edits. Choose **Rename** on a row; Enter, **Save name**, or leaving the row saves the name, while Escape or **Cancel rename** cancels it. Delete requires confirmation. **Save checkpoint** preserves an autosaved draft as a named animation, and **Save changes** updates the current checkpoint. These checkpoints stay in this browser; use a project file to share or back them up.

### Background inheritance

The sequence has one default background. A state can inherit it or opt into a frame override. Backgrounds support solid colors, gradients, and materials from the shared Shader Library, with crossfade, wipe, or radial transitions.

Changing the inherited material updates every frame that does not have an override. This prevents a seven-state sequence from becoming seven disconnected copies of the same material settings.

## Motion packages

Packages provide deterministic transition systems such as morph/fade, text-to-image, image-to-text, type/delete, crossfade, scale-fade, and slide-fade. Each package defines sensible defaults while leaving timing and frame placement editable.

Use the cubic Bézier editor when a preset is close but not exact. The selected curve is stored with the sequence and used for both preview and export.

## Audio timeline

Import authorized browser-readable audio, then place clips on the motion timeline. Clips support timeline offset, source trim, split, per-clip volume, master volume, and mute.

The waveform is derived locally from decoded audio. MP4 export mixes overlapping clips into the encoded track. GIF has no audio channel; the audio document remains available for a later MP4 export.

## Shader playback

Shader time is resolved from the animation playhead, not an unrelated wall clock. Scrubbing therefore reveals the exact material frame that export will capture. Pausing the sequence also pauses the material background.

Shader size uses the same `0.1×–10×` logarithmic zoom as Design Lab. Frame overrides store their own material settings; inherited frames track the shared background.

## Output

- **GIF** uses deterministic frame times, a protected-color palette for text/marks, and optional seamless-loop closure.
- **MP4** uses the browser's available video codec and includes mixed audio when present.
- **Poster frame** (**File → Export poster frame**) renders the frame at the playhead at full output size as PNG, through the same renderer and shader capture.
- **Source JSON** preserves sequence order, per-frame configuration (including `holdMs`, `transitionMs`, `keyframes`, `textAnimation`, `caption`, `textAnchor`, and `tracking`), background inheritance, audio state, and output settings.

Use **Download project file** for a portable, editable `.glyphfield.json` document. It includes artboards, frame timing, backgrounds, and embedded image, audio, and brand-font assets. **Open project file** validates the document and loads its assets before replacing the current animation. Imported font faces stay local to that animation workspace, so reopening a project under another brand does not rewrite the shared brand's typography. Project files preserve editable motion settings; GIF and MP4 are rendered outputs.

Choose the final dimensions and frame rate before export. Larger dimensions, more frames, live materials, converters, and global palette analysis all increase capture time.

## Agent operation

Animation is browser-rendered. An agent should open `/studio`, activate Animation, wait for `glyphfield:studio-api-ready`, inspect `describe()` and `controls()`, then use accessible controls or source read/apply.

```js
const studio = window.glyphfield.studio;
const source = JSON.parse(studio.readSource());
source.metadata.animation.playbackRate = 1;
await studio.applySource(source);
console.log(studio.describe());
```

Use the active tool's `describe().actions` list rather than guessing an export action. Verify the resulting motion in the canvas before downloading.

Scene actions return the full `animation.describe` result, so an agent can read IDs and timing once and then edit precisely:

```js
const studio = window.glyphfield.studio;
let animation = await studio.invoke('animation.starter.apply', { starterId: 'product-reel' });
const [first] = animation.scenes.filter((scene) => scene.kind === 'text');
await studio.invoke('animation.scene.update', {
  sceneId: first.id,
  holdMs: 1800,
  textAnimation: { preset: 'word-rise', durationMs: 640 },
});
await studio.invoke('animation.motion.preset', { sceneId: first.id, preset: 'push-in' });
await studio.invoke('animation.keyframe.set', { sceneId: first.id, atMs: 900, pose: { alignY: -0.05 } });
animation = await studio.invoke('animation.seek', { timeMs: first.startMs + 1200 });
const poster = await studio.invoke('animation.export.png');
```

Source validation rejects malformed motion fields with their path, for example `frameSettings.text-0.keyframes[1].atMs must be a finite number.`
