Brand elements (tool ID `brand-elements`) is the Glyphfield Studio tool that applies the active brand identity to a catalog of 89 templates. Each element renders on an artboard at its own pixel size with the identity's fonts, colors, corner radius, logos and graphic device, then scales to fit the canvas. Select an element, edit its copy on the artboard or in the inspector, adjust the composition, and export a PNG, an HTML email or a JSON brief.

Every template takes its content from the identity: products and their one-line summaries, proof, customers, published plans, the code sample and install command, and the sample person and event (see [Brand identity](/docs/studio/brand-settings#voice--strategy)). A template does not fall back to Glyphfield's own product copy.

## Catalog

`GET /api/elements` returns the catalog with each element's `id`, `name`, `category`, `dimensions`, `format`, `symbol`, `keywords` and `preview` family. The catalog size (`dimensions`) is the intended production size. When it is a pixel size with the same proportions as the artboard and larger than it, the PNG export renders at the catalog size. The 3000 × 3000 podcast cover is one example. Component sizes such as the 420 × 560 pricing card and print sizes in millimeters or inches describe the subject, so those elements export at their artboard size. The tables list the PNG size at 1×.

## Controls

Click a headline, supporting copy, action, name, role or partner name on the artboard to edit it in place. The accessible labels are **Edit headline in place**, **Edit supporting copy in place** and so on. In-place edits stay in sync with the inspector, the source and the brief.

The **Element editor** shows only the controls an element supports:

| Section | Controls |
| --- | --- |
| **Content** | **Reset element**, **Headline**, **Supporting copy** and **Action**. Person elements have **Name** and **Role**. The partnership lockup has **Partner name**. |
| **Composition** | **Layout** (Split, Stacked, Centered), **Type scale** (Compact, Balanced, Bold), **Pattern** (None, Dots, Grid, Dither) and **Pattern opacity** (0–100%) |
| **Typography** | **Font role** (any identity role) and **Weight** (100–550) for the display type |
| **Shared asset** | **Library asset** (an identity or proof asset, or **No shared asset**), **Placement** (Background, Header, Banner, Card) and **Asset opacity** (0–100%) |
| **Artwork** | **Horizontal** and **Vertical** offset (−120 to 120 px) and **Scale** (40–200%) |
| **Color** | **Background**, **Text** and **Accent** |
| **Brand details** | **Show logo** with the logo appearance controls (invert, dither, outline and shadow), and **Show website** |

Settings are stored per project and per element. **Reset element** removes the element's settings and returns it to the identity defaults.

## Export

The export preview is the dialog that shows an export with its file name and a download button.

| Action | Result |
| --- | --- |
| **Export PNG** | Renders the element with every edit at its PNG size and opens it in the export preview |
| **File** → **Export PNG at 2×** | Renders at twice the PNG size and downloads it |
| **File** → **Export HTML email** | Downloads a send-ready HTML email. Enabled for email elements only. |
| **File** → **Download element brief** | Opens the JSON brief in the export preview |

PNG files embed the brand fonts and are named `<identity>-<element>.png` or `<identity>-<element>@2x.png`. HTML files are named `<identity>-<element>.html`.

The HTML email is a 600 px table layout with inlined styles, an Outlook (MSO) wrapper, a hidden preheader of up to 140 characters, a table-based button that renders in Outlook, and absolute image URLs. Its footer links to **Unsubscribe** at `/account` on the identity's website. The content differs by element:

| Email | Content |
| --- | --- |
| Lifecycle emails | A wordmark header, header art, a greeting with the sample person's first name, the body, an action button and the template's supporting cards. The Welcome email lists up to three products when its template has no cards. |
| Enterprise emails | Plain text with a greeting and a signature from the sample person. No header or art. |
| Newsletter | Up to three items from the identity's latest update and up to three products |
| Event invitation | The date, time and place of the sample event above the headline |
| Email signature | A standalone signature block instead of the 600 px layout |
| Email system sheet | No HTML export |

The wordmark header and header art appear while **Show logo** is on. General Translation's lifecycle emails use GT's animated GIF header art, linked by absolute URL. Every other email uses a 1200 × 380 PNG of the brand's graphic device, embedded as a data URL. Host that PNG and replace its `src` before you send through a client that blocks data URLs, such as Gmail.

## Source format

**File** → **Edit source code** shows the selected element as `glyphfield.brand-element` version 2:

```json
{
  "schema": "glyphfield.brand-element",
  "version": 2,
  "elementId": "welcome-email",
  "headline": "Welcome to Stripe",
  "body": "…",
  "cta": "Open workspace",
  "layout": "stacked",
  "accentColor": "#533AFD"
}
```

Applying source selects `elementId` when it is present. It stores only the values that differ from the identity defaults, so untouched copy keeps following identity edits. Omitted settings keep their current values, so `{ "elementId": "x-post" }` only selects an element. Colors are six-digit HEX, and enum values must match the editor options. Numbers are clamped: artwork offsets to ±120, artwork scale to 40–200, opacities to 0–100 and font weight to 100–900 (displayed at most 550). Text is limited to 400 characters for the headline, 2000 for the body, 200 for the action and the role, and 120 for the name and the partner name. Unknown keys are ignored. A version 1 document has no `elementId` and applies to the selected element.

## Browser API

The Browser API (`window.glyphfield.studio`) exposes these actions while Brand elements is the active tool. An export artifact is an object with a non-empty `blob` and a `fileName`.

| Action | Input | Output |
| --- | --- | --- |
| `brand-element.export.png` | `{ elementId?, scale?: 1 \| 2, download? }` | An export artifact. `width` and `height` are the PNG size. Selects `elementId` first. |
| `brand-element.export.html` | `{ elementId?, assetOrigin?, download? }` | An export artifact. `previewText` holds the HTML. `assetOrigin` sets the origin of image URLs (default: the Studio origin). It renders `elementId` without selecting it. |
| `brand-element.export.brief` | None | An export artifact with the brief JSON |

The browser brief is `{ element, settings, identity: { colors, id, name, shortName, tagline, typography, voice, website }, schemaVersion: 2 }`.

## HTTP

`GET /api/elements` returns `{ categories, count, elements, generation, schemaVersion: 1 }`. `POST /api/generate` with `kind: "element-brief"` and an `elementId` returns `{ element, generation: { previewFamily, source }, identity, schemaVersion: 1 }`. The HTTP brief resolves the element against an identity but has no editor settings. See [Generation API](/docs/agents/generate#element-brief). A document from the source drawer is not an HTTP request body.

## Limits

- PNG export at 1× or 2× of the PNG size, which is the catalog pixel size when it matches the artboard's proportions and the artboard size otherwise.
- HTML export for email elements only.
- Font weights display up to 550.
