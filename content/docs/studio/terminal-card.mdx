Terminal card (tool ID `terminal`) renders a code window in the identity's code font and a theme built from its colors. Each built-in identity starts with real code from its product: `gt-next` for General Translation, a PaymentIntent for Stripe, a Worker for Cloudflare, `docs.json` for Mintlify, utility classes for Tailwind CSS. Custom identities start from the General Translation sample.

## Content controls

- **Card title** edits the title layer.
- **Language** sets the active tab's language: TypeScript, TSX, JavaScript, Python, Bash, JSON, HTML, or CSS. When the tab still holds one of the three General Translation samples, switching to TypeScript, Python, or Bash swaps in that language's sample; other code stays.
- The **Source** section shows the window's tabs. **Show tab** buttons switch tabs, **Add file tab** (named `file-N`, with sample code) and **Remove tab** manage them; the window keeps at least one tab, **Tab name** renames the active one, and **Terminal source code** edits its code.
- **Highlighted lines** takes a list such as `2, 4-6`. Highlighted lines get a tinted band and an accent rule.
- **Terminal title font**, **Title weight**, **Terminal code font**, and **Code weight** set the type roles.
- **Terminal card background** places an identity or proof image behind the card; **Asset opacity** controls it (default 14%).

Select the code window for **Code theme** (Brand dark, Brand light, or Classic dark), **Window chrome** (file tabs, window, or none), **Show line numbers**, **Code size** (9–48 px), line height (100–240%), and corner radius (0–64). In the brand themes, token colors come from the brand roles and are adjusted until they reach 4.5:1 against the window (3:1 for comments and punctuation). Classic dark uses a fixed palette. Long lines wrap inside the window after a space or punctuation, with the continuation indented two spaces past the line's own indent and no new line number; a highlighted line keeps its band across its wrapped rows. Code shrinks only when the wrapped code is taller than the window, and never below 80% of its set size. Templates set code between the format's body and lead sizes (18 to 25px on a 1200 × 630 card).

Layouts: **Card** (`card`; title row above a window that fills the rest of the card), **Split** (`split`; copy beside the window), **Focus** (`focus`; the window alone with a small footer), and **Caption** (`caption`; window above a caption). Formats are the same as OpenGraph.

## Export

**Export PNG** renders the card at 2×. **More exports → Export SVG** downloads a self-contained SVG with the code font embedded.

## Browser actions

| Action | Use |
|---|---|
| `terminal.export.png` / `terminal.export.svg` | Export |
| `terminal.tab.add` / `terminal.tab.select` / `terminal.tab.update` / `terminal.tab.remove` | File tabs, code, language, and highlighted lines |
| `terminal.document.describe` | Format, layouts, pages, and layers |
| `terminal.layer.add` / `terminal.layer.update` / `terminal.layer.remove` / `terminal.layer.duplicate` | Layer edits |
| `terminal.layer.reorder` / `terminal.layer.select` / `terminal.layer.align` | Stack, selection, and alignment |
| `terminal.format.set` / `terminal.layout.apply` / `terminal.template.reset` | Format, layout, and template |
| `terminal.history.undo` / `terminal.history.redo` | History |

`terminal.tab.add` takes `{ name?, language?, code? }` (default name `file-N.ts`) and returns `{ tabId }`. `terminal.tab.update` takes `{ tabId, name?, language?, code?, highlight? }`, where `highlight` is a list of 1-based line numbers. `studio.set('Terminal source code', 'const ok = true;')` still edits the active tab, and source keeps flat `code` and `language` fields that mirror it.

## HTTP

`POST /api/generate` with `{ kind: 'template', template: 'terminal', language?, body? }` renders the card as SVG. `body` is the code, up to 4000 characters. See [Generation API](/docs/agents/generate#templates).
