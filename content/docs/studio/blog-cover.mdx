Blog cover (tool ID `blog`) makes editorial covers. It starts from one of the identity's voice phrases as the headline. Layouts: **Editorial** (`editorial`; the mark alone at the top, the headline anchored above the footer), **Feature image** (`feature`; headline beside a library image or the brand device), **Statement** (`statement`), **Centered** (`centered`), and **Index** (`ledger`; logo and rule, headline, ruled footer). No layout puts a label above the headline. General Translation defaults to Editorial; most other identities default to Feature image.

## Content controls

- **Title**, **Typography role**, and **Font weight** edit the headline.
- **Surface** chooses **Base white**, **Base dark**, **Grid**, or **Noise**. Grid and noise add a texture layer you can restyle or remove.
- **Add background image** and **Brand background asset** place a full-bleed image behind the copy; **Background image opacity** controls it (default 28%).
- **Page surface** in Format and layout sets any brand color role.

Every layer is editable on the canvas; see [Expression tools](/docs/studio/templates). Formats are the same as OpenGraph.

## Export

**Export PNG** renders the cover at 2× (2400 × 1260 for the default format). **More exports → Export SVG** downloads a self-contained SVG.

## Browser actions

| Action | Use |
|---|---|
| `blog.export.png` / `blog.export.svg` | Export |
| `blog.document.describe` | Format, layouts, pages, and layers |
| `blog.layer.add` / `blog.layer.update` / `blog.layer.remove` / `blog.layer.duplicate` | Layer edits |
| `blog.layer.reorder` / `blog.layer.select` / `blog.layer.align` | Stack, selection, and alignment |
| `blog.format.set` / `blog.layout.apply` / `blog.template.reset` | Format, layout, and template |
| `blog.history.undo` / `blog.history.redo` | History |

## HTTP

`POST /api/generate` with `{ kind: 'template', template: 'blog', layout?, title, backgroundImageDataUrl? }` renders the cover as SVG. See [Generation API](/docs/agents/generate#templates).
