Typography (tool ID `typography`) edits the identity's four type roles (Display, Body, Accent and Code) and its modular type scale. Changes write to the identity as pending changes. Select **Save changes** when the Studio asks, or switch to Brand identity and call `identity.save`.

## Roles

**Add font file to identity** stores an OTF, TTF, WOFF, or WOFF2 file with the identity. The family name comes from the file name, and bold or italic in the name sets the weight and style. No license is recorded; add one in [Brand identity](/docs/studio/brand-settings#typography).

The inspector edits the selected role:

- **Typeface**: **Display font** (the font file), **Preview size** (10 up to 44 px for Display, 30 for Body, 36 for Accent, 24 for Code), **Weight** (100–550 in steps of 25), **Line height** (0.7–2), and **Tracking** (−8 to 12 px). Dragging a slider previews live; releasing commits.
- **Variable axes**: Glyphfield reads the font file's axes. When the font has an optical size axis (`opsz`), choose automatic optical sizing or a fixed size; when it has a slant axis (`slnt`), set the slant. Fonts without these axes show which axes they do have. WOFF2 files need a browser that can decode Brotli, and WOFF files need `DecompressionStream` with deflate; otherwise the axes show as not readable.
- **Type scale**: **Base size** (10–24 px), **Scale ratio preset** (Minor second, Major second, Minor third, Major third, Perfect fourth, Augmented fourth, Perfect fifth, Golden ratio), **Ratio** (1.067–1.8), and the step this role is set at.
- **Specimen**: **Sample text**, alignment (Left or Center), and **Measure** (30–90 characters).
- **Role guidance**: the role's usage and the checks below.
- **Type tokens**: the type section of the brand tokens as CSS variables, a Tailwind v4 theme or DTCG JSON.

## Modular scale

Sizes are `basePx × ratio^step` across nine steps. The default is a 16 px base and a 1.25 ratio. The steps are caption (−2), small, body (0), lead, h4, h3, h2, h1 and display (+6). Named ratios run from the minor second (1.067) to the golden ratio (1.618). By default Display is set at `display`, Body at `body`, Accent at `lead` and Code at `small`; any role can move to another step, stored as `typeScale.roleSteps`. The Scale view shows every step at its size with the roles set on it; select a step to set the selected role there, or pick a ratio from the chips.

## Guidance

Typography checks every role at its scale size:

- Leading: the recommended range is 0.95–1.15 for display sizes (28 px and up) and 1.4–1.7 for text. Warnings start below 0.85 or above 1.25 for display and below 1.35 or above 1.8 for text.
- Tracking: large display sizes take slight negative tracking, −0.01 to −0.025 em; a warning starts below −0.035 em or at any positive value, and a note at more than −0.005 em. Text sizes use 0 (a warning beyond ±0.01 em). Monospaced code is flagged below −0.005 em. **Apply recommended tracking** sets −0.02 em on large display roles and 0 on text roles that break the rule.
- Measure: 45–75 characters per line for body text.
- Scale: a base below 14 px, a ratio below 1.125 or above 1.5, and a Display role less than 1.5 times the body size.
- Weight: body text below 300.

## Views

| View | What it shows |
| --- | --- |
| Specimen | The selected role at its preview size as an editable specimen, every role on one line, the weights of the family, and the typing meter (words per minute, words, characters, seconds). Typing in any line edits the same sample. |
| Scale | The modular scale ladder with sizes in px and rem and the roles on each step. |
| Pairing | The roles together on one surface (Display on the primary color, Body, the alphabet and numerals, Code), then every display face from the brand paired with the body face, with **Use … for Display**. |
| Wrap | The headline and lead at 320, 480 and 680 px with `text-wrap: wrap`, `balance` or `pretty`. |
| Fonts | Every font file: the roles that use it, its weight range, its variation axes, its licence and source. Files without a recorded licence are marked. |

## Browser API

| Action | Result |
| --- | --- |
| `typography.tokens.read` | Type tokens as text; `{ format?: 'css' \| 'tailwind' \| 'dtcg' }` |
| `typography.tokens.copy` | The same, copied to the clipboard |
| `typography.scale.read` | Base, ratio, ratio name, each step in px and rem, and the step of each role |
| `typography.guidance.read` | The guidance list for the current roles, scale and measure |
| `typography.axes.read` | Each role's font file and its axes, or `null` when the file cannot be read |

## Source

**File → Edit source code** shows version 2:

```json
{
  "version": 2,
  "typography": [{ "role": "Display", "family": "Inter", "fontId": "inter-variable", "weight": 500, "lineHeight": 0.98, "letterSpacing": -1.2, "opticalSize": 32 }],
  "typeScale": { "basePx": 16, "ratio": 1.333, "roleSteps": { "Display": "h1" } },
  "specimen": { "sampleText": "Every language. One source.", "align": "left", "measure": 64, "previewSizes": { "Display": 40, "Body": 24, "Accent": 32, "Code": 18 } }
}
```

Roles merge by `role`. Fields that the identity's role already has are kept; unknown fields in the source and new roles are ignored. `opticalSize` is 6–144 and `slant` is −20 to 20. `opticalSize: null` and `slant: null` remove a fixed axis. Version 1 sources (`{ typography: [...] }`) still apply and leave the scale and specimen unchanged.

## Kerning and type tokens

Specimens render with `font-kerning: normal` and the `kern` feature, and optical sizing follows the size unless a role fixes `opsz`. The type tokens carry the same settings: `--brand-font-kerning`, `--brand-font-feature-settings` and `--brand-font-optical-sizing`, each role's `--brand-font-<role>-size`, and its tracking in em relative to that size (`--brand-font-display-tracking: -0.02em`), so a role keeps its tracking at any size. Tailwind steps use the same em values in `--text-<step>--letter-spacing`. `--brand-font-<role>-variation` and `-style` appear when a role fixes an axis.

## Keyboard shortcuts

Typing in a specimen line edits the shared sample. **Clear specimen and restart typing meter** resets the typing meter.

## HTTP

Typography has no HTTP route of its own. `POST /api/brand/kit` renders the type tokens with the rest of the kit, and `POST /api/generate` embeds the identity's font files in template SVGs.

## Limits

- Weights display up to 550.
- Font files are limited to 2.5 MB when added through Brand identity or `identity.font.add`.
- Axes are read from TTF, OTF, WOFF, and WOFF2 files in browsers that can decompress them.
