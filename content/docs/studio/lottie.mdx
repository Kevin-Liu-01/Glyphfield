Lottie (tool ID `lottie`) plays and edits vector animations. It accepts Lottie JSON and `.lottie` bundles, plays them in the browser with `@lottiefiles/dotlottie-web`, and composites each frame over a transparent canvas, a solid color, or a live material from the [Shader Library](/docs/studio/shader-library).

## Built-in studies

Seven studies ship with Glyphfield, each 960 × 720 at 60 FPS and 300 frames (five seconds), with the markers Build (frames 0–48), Hold (48–278), and Resolve (278–300):

| Study | ID |
| --- | --- |
| Signal relay | `signal-relay` |
| Decision router | `decision-router` |
| Source merge | `source-merge` |
| Layer assembly | `layer-assembly` |
| Quality scan | `quality-scan` |
| Network orbit | `network-orbit` |
| Endpoint delivery | `endpoint-delivery` |

A first visit starts from the identity's colors: its paper field, ink artwork, a quiet secondary, and its accent. Choosing a study loads its current design; saved compositions keep their source until you choose a study again.

## Import

| Input | Editable | Downloaded as |
| --- | --- | --- |
| Lottie JSON | Layers, text, colors, and markers | Edited JSON |
| `.lottie` bundle | Playback, trim, appearance, and background only | The original archive |

Import accepts `.lottie`, `.json`, `application/json`, and `application/zip+dotlottie`. A file is treated as a `.lottie` archive only when its name ends in `.lottie`. JSON must contain a numeric `fr` and a `layers` array. There is no file size limit. The browser player decides which Lottie features render.

## Playback

| Control | Values |
| --- | --- |
| Play or **Pause**, **Restart** | Transport |
| **Speed** | 0.1×–3× |
| **Playback direction** | Forward, Reverse, Bounce, Reverse bounce |
| **Loop**, **Frame interpolation** | Toggles |
| **In**, **Out** | Trim the segment |
| **Animation frame** | Seek to an exact frame |

## Markers

Markers name segments of the timeline. `Play marker <name>` sets the in and out frames to that segment and plays it. **Add marker at the current frame** creates "Segment N" from the current frame to the out point. Each marker has a name field (up to 64 characters) and `Remove marker <name>`. A document holds at most 64 markers. JSON markers are written into the exported document's `markers`; `.lottie` markers are read from the bundle and play the same way.

## Layers and text

**Layers** lists the document's top-level layers with their type. `Hide layer <name>` removes a layer from playback and every export without deleting it; `Show layer <name>` restores it. Layers hidden in the source cannot be shown. Text layers have `Text for layer <name>` (up to 500 characters) and `Restore original text for <name>`. Edits apply to JSON documents only. They are non-destructive: the source is kept, and the preview, frame PNG, GIF, MP4, and JSON export carry the edited result. Layer keys are each layer's `ind`, or `#<position>` when it has none.

## Appearance

| Control | Values |
| --- | --- |
| **Canvas size** | Landscape 1200 × 750, Portrait 750 × 1200, Square 960 × 960 |
| **Animation fit** | Contain, Cover, Fill, Fit width, Fit height |
| **Transparent background** | Toggle |
| **Canvas background type** | **Solid color** or **Live material** |
| **Canvas background** | Color |
| Palette buttons | **Studio** (warm paper, ink, and terracotta, with its background), **Mono** (light artwork on `#161816`), **Brand** (the identity's colors for the artwork only) |
| **Primary**, **Secondary**, **Accent artwork color** | Color, with `Use <token> for <slot>` buttons for each identity color |
| **Corner radius** | 0–48 px |
| **Stroke width** | 1–16 px; scales authored line weights together |
| **Palette recolours every paint** | The primary slot recolors every unnamed paint (the behavior of older projects) |
| **Show brand logo** | Adds the identity's logo as a "Brand logo" layer in the top-left corner. On for the built-in studies, off for imported files. Shown only when the identity has a logo |

The built-in studies recolor through the three palette slots. Imported JSON keeps its authored colors and lists every static fill, stroke, gradient stop, and text color under **Document colours**, most used first. Replace a color with the picker or a brand token, choose **Brand tokens** to map every color at once, or **Authored** to restore the originals. Brand mapping sends colors with OKLCH chroma of at least 0.06 to the brand's accents in order of chroma, and neutrals to the brand neutral nearest in lightness.

**Live material** uses the shared material controls, including a **Material** select, quick looks, palettes, and form, light, orientation, and motion settings. During export, material time follows the output clock.

## Export

| Action | Result |
| --- | --- |
| **Export frame** | PNG of the current frame and background at the canvas size, named `<id>-frame-<n>.png` |
| **GIF** | The trimmed segment at 25 FPS with a 256-color global palette that protects the three artwork colors |
| **MP4** | The trimmed segment at 30 FPS |
| **Export JSON** / **Export .lottie** | The edited JSON, or the original `.lottie` archive |

GIF and MP4 honor speed and direction; bounce modes play forward and back, so they last twice as long. GIF and MP4 have no alpha, so a transparent canvas flattens onto the canvas color. The export player needs WebGL and gives up after 10 seconds if the animation does not load. The JSON export includes appearance changes (corner radius, stroke width, brand font) and, when **Show brand logo** is on, a "Brand logo" layer.

## Source format

**File → Edit source code** shows a CanvasDocument schema 2. `metadata.studio` is `{ sourceVersion: 1, toolId: "lottie", state }`, where `state` holds `appearance` (including `recolor` and `brandLogo`), `background` (`color`, `materialId`, `materialSettings`, `style`, `transparent`), `canvasPreset`, `edits` (`colorMap`, `hiddenLayers`, `markers`, `textOverrides`), `playback` (`fit`, `interpolate`, `loop`, `mode`, `segmentStart`, `segmentEnd`, `speed`), and `source` with the raw animation in `source.data`. A `.lottie` archive is stored as an asset of the `lottie-animation` element.

Raw Lottie JSON can also be pasted into the drawer. Applying it replaces the animation, clears all edits, sets `recolor` to `source`, and sets `brandLogo` to `false`. A saved document without `brandLogo` shows the logo for a Glyphfield example and hides it for an import.

## Browser API

| Action | Input | Output |
| --- | --- | --- |
| `lottie.describe` | None | `{ format, source, totalFrames, frameRate, segment, layers, textLayers, colors, markers, edits, recolor, brandLogo }` |
| `lottie.edit` | `{ hiddenLayers?, colorMap?, textOverrides?, markers?: [{ name, frame, duration }], recolor?: 'palette' \| 'source', brandLogo?: boolean }`; each listed field replaces the stored one | `lottie.describe` result |
| `lottie.colors.brand` | None | `lottie.describe` result |
| `lottie.segment.set` | `{ marker }` or `{ start, end }` | `lottie.describe` result |
| `lottie.export` | `{ format: 'png' \| 'source' \| 'gif' \| 'mp4', download? }` | Export artifact |
| `lottie.export.frame.png`, `.gif`, `.mp4`, `.source` | None | Export artifact |

`lottie.edit` and `lottie.colors.brand` work on JSON documents and reject `.lottie` archives. `lottie.edit` rejects unknown layer keys, malformed colors, and invalid marker frames with the field path. To get the edited JSON, call `lottie.export.source`; `readSource()` returns the CanvasDocument envelope.

```js
const studio = window.glyphfield.studio;
const file = new File([lottieJson], 'animation.json', { type: 'application/json' });
studio.set('Import .lottie or JSON', file);
// Wait for the import, then:
const lottie = await studio.invoke('lottie.describe');
const title = lottie.textLayers[0];
await studio.invoke('lottie.edit', {
  hiddenLayers: [lottie.layers.at(-1).key],
  textOverrides: { [title.key]: 'Edge by default.' },
  recolor: 'source',
});
await studio.invoke('lottie.colors.brand');
await studio.invoke('lottie.segment.set', { marker: 'Hold' });
const gif = await studio.invoke('lottie.export.gif');
```

## HTTP

Lottie has no HTTP generation route.

## Limits

- Markers: 64 per document; names 64 characters. Text overrides: 500 characters.
- Layer, text, and color edits need a JSON document.
- Export needs WebGL and a browser video encoder for MP4.
- LottieFiles is a discovery link, not a mirrored library. Check each animation's license before use.
