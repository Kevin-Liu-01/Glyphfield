A tactile background is a standalone SVG made by `POST /api/generate` with `kind: "background"`. It needs no browser and no WebGL, so the same request always returns the same file. Use it when a live shader is not required, for example as a fixed background in a web page or as an image layer in Design Lab.

## Settings

All settings are optional. Read `GET /api/generate` for the current contract.

| Setting | Values |
| --- | --- |
| `width`, `height` | 64–4096 px; at most 12,000,000 pixels in total |
| `style` | `gradient`, `grain-gradient`, `dither`, `pattern` |
| `gradient` | `linear`, `radial`, `mesh`, `orbit`, `wave`, `bloom` |
| `colorA`, `colorB`, `colorC` | Six-digit HEX; default to the identity colors |
| `angle` | −360 to 360 |
| `focalX`, `focalY` | 0–100 |
| `grain` | 0–100 |
| `relief` | 0–80 |
| `bandCount`, `bandDepth`, `bandGap` | 3–24, 0–100, 0–64 |
| `lightingEnabled` | `false` gives flat bands without gradient lighting |
| `ditherMatrix`, `ditherShape` | Bayer 2, 4, or 8; `dots` or `squares` |
| `pattern`, `patternOpacity`, `spacing` | `none`, `dots`, `lines`, `grid`, `fibers`, `speckles`, `topographic`, `crosshatch`; 0–100; 8–256 px |
| `surfaceMaterial` | `none`, `kerf-wood`, `woven-wire`, `perforated-metal`, `carved-stone`, `embossed-paper`, `brushed-metal`, `hammered-foil`, `corrugated-polymer`, `cork-composite`, `frosted-glass`, `iridescent-film`, `holo-cloth`, `linen-weave`, `felted-wool`, `pebbled-leather`, `crackle-glaze`, `sandblasted-plaster`, `graphite`, `carbon-twill` |
| `surfaceScale`, `surfaceAngle` | 12–140, 0–180 |
| `surfaceDepth`, `surfaceRoughness`, `surfaceMetallic`, `surfaceIrregularity`, `surfaceTextureAmount` | 0–100 |
| `surfaceOpenArea` | 0–92 |
| `surfaceLibraryAssetId` | Empty, or one of the CC0 references below |
| `logoTone`, `logoColor` | `black` or `white`; six-digit HEX |
| `logoScale`, `logoOpacity`, `logoX`, `logoY` | 5–90, 0–100, −50 to 50, −50 to 50 |

## CC0 surface references

`surfaceLibraryAssetId` selects one of eleven CC0 references from Poly Haven and ambientCG: `polyhaven-velour-velvet`, `ambientcg-fabric-061`, `ambientcg-leather-037`, `polyhaven-oak-veneer`, `polyhaven-plywood`, `polyhaven-marble`, `polyhaven-metal-plate`, `ambientcg-metal-063`, `polyhaven-beige-wall`, `polyhaven-rubber-tiles`, and `ambientcg-paper-006`. `GET /api/surface-textures/{assetId}/{map}` serves their `color`, `displacement`, `metalness`, `normal`, and `roughness` maps with `X-Surface-License` and `X-Surface-Provider` headers. It serves only these assets and maps; it is not a general proxy. `/api/catalog` publishes the recipes, references, and attribution under `surfaceLibrary`.

## Example

```bash
curl -fsS -X POST http://localhost:3012/api/generate \
  -H 'Content-Type: application/json' \
  -d '{
    "kind": "background",
    "identity": { "preset": "gt" },
    "settings": {
      "width": 1600,
      "height": 900,
      "style": "grain-gradient",
      "gradient": "mesh",
      "surfaceMaterial": "embossed-paper",
      "surfaceDepth": 36,
      "surfaceRoughness": 72,
      "colorA": "#F4F4F4",
      "colorB": "#070707",
      "colorC": "#2F5CE0"
    },
    "output": "raw"
  }' -o tactile-background.svg
```

With `output: "raw"` the response is `image/svg+xml`. With `output: "json"` (the default) the SVG is in `artifact.content`.

## Use a background in the Studio

Add the SVG to a Design Lab artboard as an image layer, or to an expression tool as an image or background. A live shader from the [Shader Library](/docs/studio/shader-library) is the moving alternative. Foundations for the colors come from [Color tokens](/docs/studio/colors) and [Brand identity](/docs/studio/brand-settings).

## Limits

- 64–4096 px per side and 12,000,000 pixels in total; larger requests return `invalid_dimensions` or `pixel_limit`.
- Request bodies up to 5 MB. Remote image URLs are not fetched.
- The SVG is deterministic: the same request returns the same file.

See [Generation API](/docs/agents/generate) for the request envelope and errors.
