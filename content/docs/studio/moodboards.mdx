Moodboard (tool ID `design-board`) composes the active identity as a presentation board of tiles on a 12-column grid. Every tile is built from the identity: its graphic device, logos, type, palette, voice, products, proof, and library images. Tiles can be reordered, hidden, resized, recolored, and rewritten.

## Compositions

| Board | ID | Ratio | Layout size | Default tiles |
| --- | --- | --- | --- | --- |
| Showcase | `showcase` | 16:9 | 1600 × 900 | Key visual, poster series, type, color, imagery, social series, voice, business cards |
| Campaign | `campaign` | 16:9 | 1600 × 900 | Key visual, billboard, posters, social, email, event badge, website, proof |
| System | `system` | 4:5 | 1600 × 2000 | Logo, concept, type scale, color proportion, device construction, imagery, voice, motion, proof, applications |
| Specimen | `specimen` | 4:5 | 1600 × 2000 | Display face, pairing, type scale, character set, voice in type, color proportion, contrast pairs, tonal ramps |
| Catalog | `catalog` | 2:3 | 1600 × 2400 | Every tile, plus indexes of all source assets (6 columns) and all generated applications (3 columns) |

Showcase and Campaign follow the identity's art direction, so their tile mix differs between identities.

## Tiles

Select a tile on the board or in the **Tiles** list. The list shows each tile's name, layout, and width, with these controls:

- `Hide <tile> tile <id>` or `Show <tile> tile <id>` toggles the tile. Remaining tiles reflow.
- `Select <tile> tile <id> in list` selects it.
- `Move <tile> tile <id> earlier` and `Move <tile> tile <id> later` reorder it. Dragging a tile onto another on the board also reorders.

The tile inspector has **Reset tile**, **Tile layout** (the tile's variant), **Tile size** (3, 4, 6, 8, or 12 columns; rows always fill the width), **Tile surface** (Paper, Muted, Ink, Deep, Accent; text color follows for contrast), **Tile image** (the graphic device or a library image, on image tiles), and **Tile headline**, **Tile body**, and **Tile caption** (up to 600 characters each). With a tile selected, its text on the board is editable in place through `Edit <tile> headline`, **body**, or **caption**. Escape clears the selection.

| Tile kind | Layouts |
| --- | --- |
| Key visual (`cover`) | device, image, type |
| Poster | device, image, type |
| Billboard | device, image |
| Graphic device | field, construction, crops |
| Logo | pair, single, clearspace |
| Typography (`type`) | glyph, scale, phrases, pairing, charset |
| Colour (`palette`) | proportion, swatches, pairs, tints |
| Imagery | single, pair, triptych |
| Statement | concept, promise |
| Voice | quote, dodont |
| Proof | figures, list |
| Motion | curve, frames |
| Social post (`social`) | post, story |
| Email | message, inbox |
| Website (`web`) | hero, product |
| Event badge (`badge`) | lanyard, card |
| Business card (`card`) | pair, front |

Image tiles are billboard, key visual, imagery, poster, social, and website.

## Export

| Action | Result |
| --- | --- |
| **Export PNG** | The board as PNG, at the size shown in the Export section |
| **File → Export SVG** | A standalone SVG of the 1600 px wide layout with brand fonts and images embedded |
| **File → Download identity JSON** | The complete active `BrandIdentity` |

**Output size** offers Standard (1600 px wide), Retina (2400, the default), High (3200), Ultra (4800), and Custom (**Custom width** 800–4800 in steps of 100). The preset sets the export width; the height follows the board ratio. The PNG is then rendered at a pixel ratio between 1 and 2, chosen so that its long edge does not exceed 4800 px unless the preset itself is larger. The resulting PNG sizes are:

| Preset | 16:9 boards | 4:5 boards | Catalog |
| --- | --- | --- | --- |
| Standard | 3200 × 1800 | 3200 × 4000 | 3200 × 4800 |
| Retina | 4800 × 2700 | 3840 × 4800 | 3200 × 4800 |
| High | 4800 × 2700 | 3840 × 4800 | 3200 × 4800 |
| Ultra | 4800 × 2700 | 4800 × 6000 | 4800 × 7200 |

The Export section shows the exact pixel size before export. Both PNG and SVG embed every brand font and library image, so the output matches the preview.

## Source format

**File → Edit source code** shows `glyphfield.moodboard` version 2:

```json
{
  "schema": "glyphfield.moodboard",
  "version": 2,
  "composition": "showcase",
  "exportPresetId": "retina",
  "customWidth": 2400,
  "boards": {
    "showcase": {
      "title": "Brand showcase",
      "surface": "light",
      "tiles": [
        { "id": "cover", "kind": "cover", "label": "Key visual", "variants": ["device", "image", "type"], "hidden": false, "variant": "device", "span": 8, "tone": "deep", "assetId": "", "copy": { "headline": "Financial infrastructure for the internet.", "body": "…", "caption": "stripe.com" } }
      ]
    }
  }
}
```

- `composition` is `showcase`, `campaign`, `system`, `specimen`, or `catalog`. Board keys must be one of these.
- Tile order is the order of `tiles`. A partial list moves the listed tiles first; omitted tiles keep their settings. Tile IDs must be unique.
- `variant` must be one of the tile's `variants`; `span` is 3, 4, 6, 8, or 12; `tone` is `paper`, `muted`, `ink`, `deep`, or `accent`; `assetId` is an eligible library image or empty for the graphic device.
- `title` holds up to 120 characters and copy fields up to 600. Values equal to the identity defaults are not stored, so untouched copy keeps following later identity edits.
- Version 1 documents (`composition`, `exportPresetId`, `customWidth`) still apply and keep the current tile edits.

Board source configures presentation only. Content, assets, fonts, and art direction come from Brand identity.

## Browser API

| Action | Input | Output |
| --- | --- | --- |
| `moodboard.export.png` | None | Export artifact with the PNG |
| `moodboard.export.svg` | None | Export artifact with the SVG |
| `moodboard.export.identity` | None | Export artifact with the identity JSON |

Tile controls use the labels above. In the Specimen board several tiles share a kind, so **Select Typography tile** matches more than one tile; use the list labels with the tile ID instead.

## Limits

- PNG long edge up to 4800 px, except Ultra on 4:5 and Catalog boards (6000 and 7200 px).
- SVG always uses the 1600 px wide layout.
- Board title 120 characters; tile copy 600 characters.
