Every major Studio artifact can be edited visually or as structured source. The **Code** action opens a right-side drawer without replacing the canvas, so the source, inspector controls, preview, persisted draft, and export continue to describe the same artifact.

## Open the source drawer

1. Open a project and choose a Studio tool.
2. Select **Code** in the tool header.
3. Edit the current source in the right drawer.
4. Select **Apply** to validate the document and update the live tool.
5. Inspect the canvas before downloading or continuing visually.

**Reset** restores the drawer to the current visual snapshot. **Close** hides the drawer without changing the tool. Invalid source remains unapplied and produces an inline error with the field or format that needs attention.

## What can be edited

| Studio surface | Source format | Applied result |
| --- | --- | --- |
| Brand settings | Complete `BrandIdentity` JSON | Replaces the active identity after required collections validate |
| Brand elements | Selected element override JSON | Updates the selected application and its visual preview |
| Moodboard | Composition and export JSON | Changes board mode and output dimensions |
| Animation | Sequence, timing, frame, and playback JSON | Updates the same frame model used by preview and GIF export |
| Lottie | Raw Lottie JSON | Replaces the vector document and rebuilds playback |
| Material | Material-engine JSON with optional GLSL source | Updates the live WebGL material, logo target, finish, and export settings |
| Surface Lab | Background, logo, asset, and appearance JSON | Updates the shared surface canvas and PNG output |
| OpenGraph and templates | Tool-specific content, layout, surface, and layer JSON | Updates the selected graphic and its exported PNG |
| Color and typography | Token and font-role JSON | Updates identity-bound foundation previews |
| Terminal and components | Tool-specific configuration JSON | Updates the rendered card or component family |

See [Source format reference](/docs/reference/source-formats) for field-level constraints.

## Animation source

Animation uses one JSON object. `textFrames` is a newline-delimited string, while `sequenceOrder` determines where text, logo, and image states appear.

```json
{
  "mode": "sequence",
  "textFrames": "Welcome\n你好\nようこそ",
  "includeBrandLogo": true,
  "sequenceOrder": ["brand-logo", "text-0", "text-1", "text-2"],
  "playbackRate": 1,
  "settings": {},
  "frameSettings": {}
}
```

Start from the source already shown in the drawer and change only the fields you need. This preserves the complete timing and per-frame objects produced by the visual editor.

## Lottie source

Imported Lottie JSON is edited as the animation document itself rather than as a Glyphfield wrapper.

```json
{
  "v": "5.12.2",
  "fr": 60,
  "ip": 0,
  "op": 180,
  "w": 1200,
  "h": 750,
  "layers": []
}
```

The editor requires a numeric `fr` and a `layers` array. A binary `.lottie` bundle cannot be converted into editable text automatically; import or select a JSON source before using the drawer. The original bundle remains downloadable.

## Material and GLSL source

Material source keeps renderer selection, colors, parameters, live-material settings, surface finish, logo placement, output ratio, quality, and speed in one object. Custom shader text is stored in `customSource`.

```json
{
  "engine": "custom-glsl",
  "target": "both",
  "ratio": "opengraph",
  "exportQuality": "high",
  "colors": ["#181818", "#ffffff", "#a8a8a8"],
  "customSource": "void main() { /* use the supplied uniforms */ }"
}
```

Use the current drawer source when authoring a shader so the engine-specific parameters and finish values remain intact. The material canvas recompiles only after a valid document is applied.

## Validation and shared state

- The drawer accepts JSON objects, not arrays or primitive values.
- Tool-specific enums and numeric ranges validate before the visual state changes.
- Applying valid source updates the same project-scoped draft used by the inspector.
- Subsequent visual edits regenerate the source representation.
- Preview and export resolve from the applied tool state, not from an isolated code sample.
- Source editing does not bypass asset authorization, font availability, or export preflight.

## Source drawer versus the agent API

The drawer is a browser-local editing surface for an open project. `POST /api/generate` is the stable public contract for deterministic SVG and JSON generation. They share identity concepts, but their payloads are not interchangeable.

Agents operating the browser may open **Code**, edit the current document, apply it, visually verify the canvas, and use the visible download action. Headless integrations should use [`/api/generate`](/docs/agents/generate) and validate against `/openapi.json` instead.
