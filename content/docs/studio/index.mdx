The Studio is the visual workspace at `/studio`. A project holds one brand identity and a separate draft for every tool. Fifteen tools read that identity; `GET /api/labs` returns the current list. Every tool has a JSON source document, browser-rendered exports, and a `window.glyphfield.studio` Browser API adapter.

## Open a tool

- Choose a tool in the left navigation. At laptop widths the navigation becomes an icon rail with tooltips.
- Press ⌘/Ctrl + K, or / when no field has focus, to open **Search Studio tools**. Search matches the typed text inside each tool's name, group, description, and keywords. Use the arrow keys to move, Enter to open, and Escape to close. The letter beside each result is a visual hint, not a key binding.
- Open a URL: `/studio?tool=<id>&project=<project id>&folder=<folder id>`. The Studio updates these parameters as you navigate.

The header also links to **Docs** and **Quickstart**.

## Projects and tabs

Project tabs sit above the tool. Each tab is a view of a saved project; closing a tab never deletes the project.

| Control | Action |
| --- | --- |
| **+** (**Add brand project**) | Opens **New project**: **Start from scratch** with an empty Design Lab design, Animation, or Brand identity; **Use a template** to copy one of the nine built-in identities; **Import project…** to open a `.glyphfield.json` file as a new project |
| **Project** menu | **Duplicate active project**, **Close other project tabs**, and, for your own projects, **Delete active project** |
| **Projects** menu | Folders **All projects**, **Templates**, **My brands**, and **Examples**, with counts; reopens closed projects |
| Tab menu (right-click, Shift + F10, or the ContextMenu key) | **Open project**, **Rename project** (F2, your own projects only), **Duplicate project**, **Move tab left** (Option/Alt + ←), **Move tab right** (Option/Alt + →), **Close tab**, **Close other tabs** |

Drag a tab to reorder it; neighboring tabs move aside to show the insertion point. When tabs do not fit, they become compact, then icon-only, then scrollable with scroll buttons.

**Duplicate** copies the identity, the current work in every tool, assets, and saved checkpoints, including edits still waiting to autosave. The copy opens in a new tab and is independent. If a canvas is still loading or an asset cannot be copied, an **Error** button explains why and no empty copy is created. **Use a template** creates `<Name> copy 1` from the built-in identity without copying any tool work.

**Delete active project** opens a confirmation that names the project. **Delete project** removes it from your projects in this browser; **Cancel**, Escape, or a click outside the dialog keeps it. A deleted project cannot be restored. Built-in projects cannot be deleted or renamed; edits to them are kept, and **Restore the shipped version** in Brand identity returns one to its shipped state.

The nine built-in identities are listed in [Built-in identities](/docs/studio/brand-settings#built-in-identities).

## Where controls live

| Place | Purpose |
| --- | --- |
| Project tabs, **Project**, **Projects** | Switch, create, duplicate, and reopen projects |
| Tool header | Save checkpoints, browse saved designs, **File**, and export actions |
| **File** menu | Portable project open and download where supported, and **Edit source code** under Advanced |
| Canvas toolbar | Zoom, fit, reset, undo, redo, and tool-specific view controls |
| Left sidebar | Libraries, catalogs, and sources |
| Right inspector | Settings of the selected layer or of the tool |

Inspector headings are disclosure buttons. Collapsed sections keep their controls and values. Color rows show a swatch and HEX value; opening a row shows the shared picker with HEX, OKLCH, hue, opacity where supported, and **Pick screen color** in browsers with the EyeDropper API.

## Canvas navigation

Most tools wrap their artifact in the shared canvas viewport:

- **Zoom out** and **Zoom in** change zoom by 10%. The **Canvas zoom** slider sets it directly. The percentage button resets to 100%.
- **Fit canvas** fits the artifact. **Reset view** returns to the starting view.
- Scrolling over the stage zooms; dragging empty workspace pans.
- ⌘/Ctrl + Z and Shift + ⌘/Ctrl + Z undo and redo while the canvas has focus or the pointer is over it.

Zoom ranges from 40% to 200% in most tools. Design Lab ranges from 5% to 800%. Zoom is saved per project and tool. View changes never change the artifact's geometry or export size.

## Visual settings

**Visual customization** in the header changes the Studio interface only. It never changes brand colors in an artifact or its exports.

| Setting | Values |
| --- | --- |
| Theme | Light, Dark, Auto. Shared with the landing page and the docs |
| Accent | Neutral, violet, teal, lime, or a custom color chosen with the color picker, for selection and focus |
| Canvas | Dots, grid, or plain workspace background |
| Corners | Rounded (default) or square controls and panels |
| Studio font | Helvetica Neue (default), Be Vietnam Pro, Schibsted Grotesk, Rethink Sans |
| Compact UI | Tighter navigation |
| Reduce motion | Pauses decorative effects |
| Tooltips | On (default) names a control when the pointer rests on it or it receives focus; off hides those hints |

Auto follows the operating system theme, including changes while the page is open. The theme is applied before the first paint. The Studio respects `prefers-reduced-motion`.

## Switching and motion

The sidebar item or project tab highlights as soon as it is clicked. The current tool stays on screen until the next one has loaded, then the new tool fades in over it in 160 ms. If loading takes longer than 180 ms, a thin progress line appears at the top of the workspace. The first time the Studio opens, a placeholder with the tool's layout (toolbar, side panel and canvas) shows until the tool is ready, then the tool fades in over it.

Tools you have opened stay in memory with their renderers paused, so switching back does not reload them. The code for the other tools loads in idle time after the first tool paints; this is skipped when the browser asks to save data.

Command search fades and lifts in. Menus, popovers and command search fade out over 120–140 ms when they close, while the control itself closes at once, so focus, automation and tests see the closed state immediately. The source drawer slides in and loads its editor the first time it opens. Collapsing a sidebar changes its width at once and fades its content back in when it expands, so the editor is not laid out again on every frame.

Replacing a shader keeps the previous one on the canvas, paused, until the new one has painted its first frame, then fades it out over 160 ms. Shader library cards start loading a Shaders.com or ShaderGradient engine when the pointer rests on them or they receive focus.

With `prefers-reduced-motion` set in the operating system, or **Reduce motion** on in Visual customization, every switch, fade and slide happens in a single frame.

## Persistence

Project identities, open tabs, the active tool and folder, visual settings, and most tool drafts are saved in this browser's `localStorage`. Design Lab saved designs, autosaves, converted assets, and captured shader frames use IndexedDB, with a small recovery journal. Nothing is uploaded to a server. Clearing site data removes local work; use [Backup and restore](/docs/artifacts/backup-and-restore) to keep copies.

## Agents in the Studio

The active tool installs `window.glyphfield.studio`. An agent can list and operate controls by accessible label, read and apply source, call tool actions, and download returned files. See [Studio Browser API](/docs/reference/browser-api) and [Choose the right interface](/docs/agents/choose-interface).
