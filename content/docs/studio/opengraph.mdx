OpenGraph (tool ID `opengraph`) makes social preview images. It starts from the identity's brand template: its headline, its promise as supporting copy, a proof chip, the brand mark, and the identity's graphic device or photograph as the media panel. General Translation gets its language field, Stripe its programmable field, Ramp its campaign photograph, Tailwind CSS its utility wave.

## Content controls

- **Headline**, **Typography role**, and **Font weight** edit the headline layer.
- **Surface** switches the page between **Base white** and **Base dark**; text and marks switch with it. **Page surface** in Format and layout sets any brand color role. General Translation defaults to ink.
- On the Split and Full bleed layouts, which have a media panel, **Add supporting image** replaces the panel with a local image and **Identity evidence** picks an image from the identity library, or **Brand device** to return to the generated device.
- **Replace logo** and **Brand logo asset** change the mark. Select the logo layer for **Logo effects** (invert, dither, outline, shadow).
- **Add font file** loads a local font for the headline.

Every layer is also editable on the canvas; see [Expression tools](/docs/studio/templates).

## Formats and layouts

Formats: `opengraph` 1200 × 630, `wide` 1600 × 900, `square` 1080 × 1080, `portrait` 1080 × 1350, `story` 1080 × 1920, `linkedin` 1200 × 627, and `lockup` 1200 × 600. Layouts: **Split** (`split`; copy beside the media panel, stacked on tall formats), **Statement** (`statement`; one large headline with a ruled footer), **Full bleed** (`media`; media behind the headline with a scrim), **Centered** (`centered`), and **Editorial** (`editorial`; a large headline from the top edge and a ruled footer with logo and website).

## Export

**Export PNG** renders the artboard at 2× (2400 × 1260 for the default format). **More exports → Export SVG** downloads a self-contained SVG. For the deployed site's own social images, see [Social previews](/docs/reference/social-previews).

## Browser actions

| Action | Use |
|---|---|
| `opengraph.export.png` | PNG at 2× of the artboard |
| `opengraph.export.svg` | Self-contained SVG |
| `opengraph.document.describe` | Format, layouts, pages, and layers |
| `opengraph.layer.add` / `opengraph.layer.update` / `opengraph.layer.remove` / `opengraph.layer.duplicate` | Layer edits |
| `opengraph.layer.reorder` / `opengraph.layer.select` / `opengraph.layer.align` | Stack, selection, and alignment |
| `opengraph.format.set` / `opengraph.layout.apply` / `opengraph.template.reset` | Format, layout, and template |
| `opengraph.history.undo` / `opengraph.history.redo` | History |

Agents can also set the labelled controls with `studio.set('Headline', 'Ship every locale')`. The shared actions are described in [Expression tools](/docs/studio/templates#browser-api).

## HTTP

`POST /api/generate` with `{ kind: 'template', template: 'opengraph', layout?, format? }` returns the same template as SVG. `body` fills the supporting copy only on layouts that have it. See [Generation API](/docs/agents/generate#templates).
